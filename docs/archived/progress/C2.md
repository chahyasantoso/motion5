## Invariant

The public React package exposes `usePatch` backed by `useSyncExternalStore`. It renders the current immutable patch, updates after publication, and does not expose `PatchRegistry` or graph internals through its public entry.

A consumer must also be able to satisfy that contract from the package entry alone. `usePatch` takes a `PatchSource` and returns a `Patch`, so exporting only `Patch` left the argument untypeable without an `@motion5/core/internal` import: the surface was public in name and unusable in practice. The entry now re-exports `Patch`, `PatchListener`, and `PatchSource`, which keeps `@motion5/core/internal` a private channel between the two packages rather than a required consumer import.
