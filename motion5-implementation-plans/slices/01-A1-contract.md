Status: not implemented. Depends on: none. Read budget: overview, shared cache contract, this slice and scoped sources.

Read `00-overview.md`, `42-cache-contract.md`, `AGENTS.md`, `docs/PR-WORKFLOW.md`, `docs/AUTHORED-SCHEMA.md`, and public types in `packages/core/src/contract/v5.ts` and `packages/core/src/domain/plugins.ts`. Follow relevant imports; do not reload historical plans.

## Outcome and work

Create proposed repository artifacts `docs/skeldata/CONTRACT.md` and a small `docs/skeldata/STATUS.md`. Record one normative answer for every authoring, identity, operation, topology, numeric, evaluator/cache, editing and rendering invariant. Name its owner and earliest validation stage: shape, registry, derivation, preparation/evaluation, publication or adapter. Allocate an actual next-available superseding ADR only if required; do not guess numbers.

Pin singleton-map IDs for every entry, independent collect/fold DELTAS, source-owned root with no IK/FK base slots, parent-linked chains/joins, anchored first point and poses map. Root-plugin position is unrestricted; topology-root-first means first JOIN. Refuse rooted imported chains. Pin shared collector append, ordered delta fold, collect/fold collision refusal and engine-stamped collection IDs. Separate root frame, point/link IDs and compiler identity. No implicit same-track collection/IK/FK connection; retain 2D-first removals, no converter/compatibility/PlanX tree and one track schedule node.

Add the generic cache decision from the shared reference. Contracts depend on a tiny provider port, not a concrete backend. Runtime services inject provider policy into per-generation evaluator factories. Plugins own effective keys and result validation; math is cache-free; the existing core transaction owns acceptance of opaque state and ready outputs. The default bounded immutable provider, no-cache and a test alternative must share one execution path and preserve accepted meaning. No FK/IK names in core dispatch, authored cache leaves, global maps or second transaction manager.

Record exactly one execution owner for a definition: stateless run callbacks or its stateful factory, with unchanged operation claims and no duplicated runner. Preserve pure stateless ergonomics and both-operation input isolation. Use exhaustive unions for true execution/lookup/binding/result variants, not a collect/fold/both mode or closed list of providers. Identify B7 as generic implementation owner, D4 as whole-solve IK consumer, D5 as per-point FK consumer and D6 as shared lifecycle proof.

## Evidence and finish

Review each invariant against a valid and minimal invalid case. Include one-point FK versus root-only IK, omitted root versus rooted import, non-kinematic slots named targets/root, both-operation isolation, two injected provider instances and late evaluation failure after each domain computes. Check that no-cache/eviction changes cost rather than semantics and that every failure has one owner.

This is a contract slice, not runtime verification. Done when later slices require no historical proposal or unstated cache choice. Report actual artifact paths, decisions, review checks and unresolved work; mark contract reviewed, not implementation finished. Next: A2.
