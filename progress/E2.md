## Findings from the first runs

- Publication ownership: reading a value straight after `seek()` asserted against Track state rather than the canonical publication. The test now flushes and asserts `runtime.graph.registry.get("hero/arm")`, which is what a real consumer observes.
- GSAP internals: the adapter's proxy carries `_gsap` bookkeeping. `Track` strips underscore-prefixed keys before composition ([`51fb91e7`](https://github.com/chahyasantoso/motion5/commit/51fb91e72411788d02047ac64e87fb6702212b4d)) so adapter internals never enter the immutable value contract.
- Easing default: GSAP's implicit `power1.out` was silently bending authored positions. Segments now compile with `ease: "none"` unless a stop authors one ([`698e4193`](https://github.com/chahyasantoso/motion5/commit/698e41935de5b748f7c65fb911750615ae922bfb)).
- Eased expectation: GSAP's `power2` is cubic, not quadratic, so `power2.in` at progress 0.5 is 0.125 and `x` is 12.5, not 25 ([`4b04eee1`](https://github.com/chahyasantoso/motion5/commit/4b04eee1d35fc46e3fcb1acce8976fd8fe1507cc)).
