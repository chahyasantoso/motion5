## Deliberate non-rule

Consumer packages are **not** scanned with `importsBoundary`, `importsRenderer`, or `bannedSymbol`. `packages/react` imports React because that is its job, and a renderer rule aimed at core layers would make the shipped tree permanently red. The planted `packages/vue/src/index.ts` imports React on purpose and the test asserts that no renderer violation is reported for it. Core layers and `packages/core/src/engine.ts` keep the full rule set.
