## Invariant

Input observations project upstream authored keys into the observer source object as flat keys before local composition. They do not arrive as a nested target blob.

## Implementation

X-1 added edge-owned `pick` and `map` projections, targetless projected inputs, deterministic edge ordering, and projected-key collision diagnostics. `GraphPublisher` now merges projected records flat before local composition.
