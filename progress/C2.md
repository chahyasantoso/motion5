The public React package exposes `usePatch` backed by `useSyncExternalStore`. It renders the current immutable patch, updates after publication, and does not expose `PatchRegistry` or graph internals through its public entry.

## Owner

The React package owns hook wiring and public exports. C1's `createPatchStore` owns source subscription lifetime. Core continues to own patch identity, freezing, and publication.

## Implementation

`usePatch(source, nodeId)` memoizes the framework-neutral C1 store by source and node ID, then delegates subscription and snapshot reads to React's `useSyncExternalStore`. React is a peer dependency, so applications provide their own React version; the local declaration keeps the workspace type boundary explicit without exporting core internals.
