## Invariant

Malformed authored projects fail at `Engine.load()` before a timeline or runtime is created.

## Implementation

`Engine.load()` now calls `validateV5()`, resolves authored plugin ownership during load, eagerly prepares every track, and disposes timelines created before a later track fails.

## Boundary

This slice covers authored data only. Runtime source shape cannot be validated at load because composed upstream values do not exist until publication. That remains covered by the runtime diagnostics follow-up in [PR #77](https://github.com/chahyasantoso/motion5/pull/77).

## Known follow-up

Validation still returns the original project through a cast rather than a branded deep-frozen validated snapshot, and validation ownership remains duplicated between the contract validator and graph IR. Those are still open review items.
