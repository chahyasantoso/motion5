## Invariant

Motion keys render through `style.transform`, and omitted CSS keys are removed with `style.removeProperty()` rather than assigned `undefined`.

## Implementation

The default DOM writer now keeps adapter-owned transform state, composes `x/y/z` as `translate3d`, preserves rotation and scale components, and removes omitted CSS properties through the style API. Transform state is cleared with the target cache.
