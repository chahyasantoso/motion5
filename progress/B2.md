## Invariant

Authored multi-stop properties compile into an adapter-owned GSAP timeline. The proxy starts at the first stop and reaches the authored values at progress `0`, `0.5`, and `1`; the adapter never initializes from the final stop and never passes only that stop to `timeline.to()`.

## Failing-first evidence

Test: [`packages/core/test/contract/gsap-multi-stop.test.ts`](../packages/core/test/contract/gsap-multi-stop.test.ts), which injects a real GSAP timeline and asserts `0`, `50`, and `100` at progress `0`, `0.5`, and `1`.

[Recovery audit run #11](https://github.com/chahyasantoso/motion5/actions/runs/31486238764) with `ref: f99f23e9` and `base: 3c311415` recorded `failing-first: pass`: red on the base implementation, green on the slice. The stale expectation in `adapters.test.ts` that the proxy starts at the final stop was corrected to the first stop in the same slice, so the two contract tests no longer disagree.

The audit's other four jobs are red on this ref and on the base: `contract` reports the missing React lifecycle and end-to-end surfaces (C1, C2, E2), `mutation` reports the missing Stryker config (E3), `acceptance` reports the missing checker and map (D3), and `build` reports unresolved declarations and public entries (E1). These are missing-gate measurements, not B2 regressions.

## Owner

The GSAP adapter owns compilation and the proxy. `compileKeyframes()` emits one segment per authored interval, with each segment's duration derived from the `p` delta and scaled by the configured duration. Track still reads the timeline's state object and never mutates it, and no sampler API was added.

## Motionpath oracle

The oracle's tween compiler is the reference for segment-per-interval compilation and for seeding the proxy from the first authored stop. Not copied: the oracle's Track-owned traversal, its publisher, and its file layout. Only the compilation behavior was ported into motion5's adapter boundary.

## Deletions

The single-`to()` last-stop shortcut is gone, along with the `compileVars()` helper that produced it. The earlier B2 branch, which carried a hand-built lockfile and a stale status copy, was abandoned in favor of this clean branch cut from the rescue tip; `gsap@3.15.0` now enters through a generated lockfile entry.
