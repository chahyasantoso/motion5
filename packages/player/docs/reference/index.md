# @gerak/player: index

- **`manualDriver`** `(options?: { readonly durationMs?: number; }): ManualDriver`: A driver moved by hand: `.seek(progress)`, `.seekMs(ms)`. Timed when given `durationMs`, untimed otherwise.
- **`play`** `<T extends object>(scene: Signal<T>, driver: Driver, options?: PlayOptions): Player<T>`: Runs `scene` against `driver`, telling each target's subscribers its value on every step.
- **`Driver`** `type Driver = { now: () => Time; events?: () => Events; subscribe: (listener: () => void) => () => void; options?: object }`: What drives a scene: the time now, the events so far when it watches any, and a signal each time it moves.
- **`ManualDriver`** `type ManualDriver = { seek: (progress: number) => void; seekMs: (ms: number) => void; now: () => Time; events?: () => Events; subscribe: (listener: () => void) => () => void; options?: object }`: A driver moved by hand, timed when it knows its length in ms.
- **`Player`** `type Player<T> = { time: Time; values: T; subscribe: <K extends keyof T>(target: K, listener: (value: T[K]) => void) => () => void; observe: <V>(signal: Signal<V>, listener: (value: V) => void) => () => void; refresh: () => void; replace: (next: Signal<T>, cues?: Events) => void; on: (name: string, listener: (event: MotionEvent) => void) => () => void; snapshot: () => PlayerSnapshot; restore: (snap: PlayerSnapshot) => void; dispose: () => void }`: A scene's values by target, rerun whole on each step of its driver.
- **`PlayerSnapshot`** `type PlayerSnapshot = { kind: "player-snapshot" }`: Immutable point-in-time capture of a player's clock time, store cells, and event state.
- **`PlayOptions`** `type PlayOptions = { cues?: Events; retention?: RetentionPolicy; onEvent?: (event: MotionEvent) => void; settleMs?: number }`: Options of `play`: `cues`, event `retention` policy, `onEvent` stream callback, and `settleMs`.
