# @gerak/react: index

- **`centreIn`** `(from: LayoutBox, to: LayoutBox): Offset`: `from`'s layout centre as an `Offset` from `to`'s top-left corner; layout ignores transforms, so this is the rest pose.
- **`mergeRefs`** `<T>(...refs: readonly RefCallback<T>[]): RefCallback<T>`: Combines ref callbacks so one element can be bound by several hooks.
- **`LayoutBox`** `type LayoutBox = { offsetLeft: number; offsetTop: number; offsetWidth: number; offsetHeight: number; offsetParent: unknown }`: The layout an element exposes; an `HTMLElement` has it.
- **`Offset`** `type Offset = { x: number; y: number }`: A point in px: `x` right and `y` down from a corner.
- **`PlayerHostProvider`** `(props: React.ProviderProps<PlayerHost>): React.ReactNode`: Gives every `usePlayer` below it a `PlayerHost`; a saved file then swaps a new `scene` or `cues` in with `player.replace`, keeping the player and its time.
- **`driverKeeper`** `(): DriverKeeper`: Makes a `DriverKeeper`: keeps its driver while a factory makes one of the same members and equal `options`; else takes the new one at the old time and disposes the old.
- **`usePlayer`** `<T extends object, D extends OwnedDriver>(scene: Signal<T>, createDriver: () => D, cues?: Input): Playing<T, D> | undefined`: Plays `scene` on a driver from `createDriver` with `cues`; define all three outside the component. Gives `Playing`, or `undefined` before it exists.
- **`useSignal`** `<T extends object, V>(player: Player<T> | undefined, signal: Signal<V>): V | undefined`: Reads a signal over the player's time and events into a render, again only when it changes by `Object.is`. Define the signal outside the component; `undefined` before the player exists.
- **`useTarget`** `<T extends object, K extends PoseTargets<T>>(player: Player<T> | undefined, target: K): RefCallback<RenderTarget> (+1 overloads)`: Writes a target onto the element the ref lands on every step, with no render. For a list target give each element its own `useTarget` with a `render` that picks its index. Writes a target onto the element the ref lands on through `render`, every step, with no React render.
- **`useValue`** `<T extends object, K extends keyof T, V>(player: Player<T> | undefined, target: K, select: (value: T[K]) => V): V | undefined`: Reads a rarely changing value of a target into a render; `select` should answer a primitive.
- **`useWatch`** `(driver: EventDriver | undefined, target: string): RefCallback<Element>`: Logs the events of the element the ref lands on to `driver` as `target`'s; put it on an element that stays still.
- **`DriverKeeper`** `type DriverKeeper = { createDriver: <D extends OwnedDriver>(own: () => D) => D; current: () => OwnedDriver | undefined; subscribe: (listener: () => void) => () => void }`: A host's one driver: kept while a factory makes the same driver, replaced at the same time when it does not.
- **`OwnedDriver`** `type OwnedDriver = Driver & { dispose?(): void; }`: A driver a component owns, released when the component leaves.
- **`PlayerHost`** `type PlayerHost = { createDriver?: <D extends OwnedDriver>(own: () => D) => D; guard?: <T extends object>(scene: Signal<T>, fallback?: T) => Signal<T> }`: What a page may take over from `usePlayer`: which driver runs the scene, and how a scene is wrapped.
- **`Playing`** `type Playing<T, D> = { player: Player<T>; driver: D }`: What `usePlayer` gives: the `player` and the `driver` it plays on.
- **`Stage`** `({ scene, options, children }: StageProps): ReactNode`: Mounts a scene over its children; a scene with the same signature swaps in, others remount.
- **`useMount`** `(ref: RefObject<PageRoot | null>, scene: StageInput, options: StageMountOptions): Mounted | undefined`: Mounts a scene onto `ref.current` without a wrapper `<div>`, swapping same-signature updates via `replace`.
- **`StageMountOptions`** `type StageMountOptions = { clock: MountClock; frame?: MountFrame; scrollTarget?: PageScrollTarget; frames?: FrameSource; settleMs?: number; now?: () => number; viewport?: () => { readonly width: number; readonly height: number; }; onDriver?: (driver: Driver) => void; checks?: boolean; nodes?: Readonly<Record<string, PageElement | readonly PageElement[]>>; binders?: readonly Binder[] }`: What `useMount` and `<Stage />` mount with: the options of `mount`, whose root is supplied via ref.
- **`StageProps`** `type StageProps = { scene: StageInput; options: StageMountOptions; children?: ReactNode }`: What `<Stage />` plays: a scene (or compiled stage) over its children, which hold the cast's markup.
