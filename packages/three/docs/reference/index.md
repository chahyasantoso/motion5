# @gerak/three: index

- **`morphTargets`** `(root: Object3D): CustomWriter`: Builds a `CustomWriter` that writes `[0, 1]`-clamped values into matching `morphTargetInfluences` under `root`.
- **`applyPose2d`** `(object: Object3D, pose: Pose2d, rest?: Point2d, custom?: CustomWriter): void`: Writes a 2D pose on an object: y and rotation flip for its axes; calls `custom(name, value, object)` for each custom number; leaves blur, stroke, clip and layer alone.
- **`UNWRITTEN_2D`** `const UNWRITTEN_2D: Readonly<Partial<Record<CarriedBy<"both" | "2d"> | CarriedBy<"3d"> | "anchor" | "custom", string>>>`: The 2D pose fields `applyPose2d` leaves alone, each with the reason.
- **`WRITTEN_2D`** `const WRITTEN_2D: readonly ["x", "y", "rotation", "scale", "scaleX", "scaleY", "opacity", "anchor"]`: The 2D pose fields `applyPose2d` writes on an object; custom numbers go to the piece's own writer.
- **`CustomWriter`** `type CustomWriter = (name: string, value: number, object: Object3D) => void`: Where a piece puts a custom number on an object; the renderer knows no meaning for it.
- **`applyPose3d`** `(object: Object3D, pose: Pose3d, rest?: Point3d, custom?: CustomWriter): void`: Writes a `Pose3d` on an object: y up, degrees on Z-X-Y; a missing field writes its rest, and each custom number goes to `custom(name, value, object)`.
- **`setEulerDegrees`** `(target: Euler, rotation: number, rotationX: number, rotationY: number): Euler`: Sole degrees-to-radians owner for `ZXY`; angles reduce mod 360.
- **`UNWRITTEN_3D`** `const UNWRITTEN_3D: Readonly<Partial<Record<"x" | "scale" | "y" | "z" | "scaleX" | "scaleY" | "scaleZ" | "opacity" | "anchor" | Turn3d | "custom", string>>>`: The 3D pose fields `applyPose3d` leaves alone, each with the reason; it writes every one.
- **`WRITTEN_3D`** `const WRITTEN_3D: readonly ["x", "y", "z", "rotation", "rotationX", "rotationY", "scale", "scaleX", "scaleY", "scaleZ", "opacity"]`: The 3D pose fields `applyPose3d` writes on an object; custom numbers go to the piece's own writer.
- **`threeBinder`** `(root: Object3D, options?: ThreeBinderOptions): ThreeBinder`: Binds a scene's object elements to the `Object3D` of the same name under `root`, or to `objects[name]`.
- **`ObjectTarget3d`** `type ObjectTarget3d = Object3D<Object3DEventMap> | ((pose: Pose3d, visible: boolean) => void)`: Where a scene's object goes: an `Object3D`, posed from its position when bound, or a writer that takes the pose and whether the object shows, such as one handing bone poses to `applyBones`.
- **`ThreeBinder`** `type ThreeBinder = { claims: (name: string) => boolean; start: (player: Player<Readonly<Record<string, unknown>>>, stage: Stage) => () => void }`: What a mount runs to draw the object elements of a scene: which it claims, and how it starts.
- **`ThreeBinderOptions`** `type ThreeBinderOptions = { objects?: Readonly<Record<string, ObjectTarget3d>>; draw?: () => void }`: Settings of `threeBinder`: targets that override the match by name, and the draw run once each step.
- **`useTarget3d`** `<T extends object, K extends Pose3dTargets<T>>(player: Player<T> | undefined, target: K, options?: { readonly invalidate?: () => void; }): RefCallback<Object3D> (+1 overloads)`: Writes a 3D pose target on the object the ref lands on, every step, with no render; its position then is its rest. With `at`, binds only the `at`th pose of a list target; a missing index writes nothing, a bad one throws.
