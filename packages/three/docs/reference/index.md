# @gerak/three: index

- **`morphTargets`** `(root: Object3D): CustomWriter`: Builds a `CustomWriter` that writes `[0, 1]`-clamped values into matching `morphTargetInfluences` under `root`.
- **`applyPose2d`** `(object: Object3D, pose: Pose2d, rest?: Point2d, custom?: CustomWriter): void`: Writes a 2D pose on an object: y and rotation flip for its axes; calls `custom(name, value, object)` for each custom number; leaves blur, stroke, clip and layer alone.
- **`UNWRITTEN_2D`** `const UNWRITTEN_2D: Readonly<Partial<Record<CarriedBy<"both" | "2d"> | CarriedBy<"3d"> | "anchor" | "custom", string>>>`: The 2D pose fields `applyPose2d` leaves alone, each with the reason.
- **`WRITTEN_2D`** `const WRITTEN_2D: readonly ["x", "y", "rotation", "scale", "scaleX", "scaleY", "opacity", "anchor"]`: The 2D pose fields `applyPose2d` writes on an object; custom numbers go to the piece's own writer.
- **`CustomWriter`** `type CustomWriter = (name: string, value: number, object: Object3D) => void`: Where a piece puts a custom number on an object; the renderer knows no meaning for it.
- **`applyPose3d`** `(object: Object3D, pose: Pose3d, rest?: Point3d | Rest3d, custom?: CustomWriter): void`: Writes a `Pose3d` on an object: y up, degrees on Z-X-Y; a missing field writes its rest, and each custom number goes to `custom(name, value, object)`.
- **`captureRest3d`** `(object: Object3D, sharedMaterials?: ReadonlySet<Material>): Rest3d`: Captures position, rotation quaternion, scale, visibility, and material baseline of `object`.
- **`restoreRest3d`** `(object: Object3D, rest: Rest3d): void`: Restores `object` to its captured `Rest3d` transform, visibility, and materials.
- **`setEulerDegrees`** `(target: Euler, rotation: number, rotationX: number, rotationY: number): Euler`: Sole degrees-to-radians owner for `ZXY`; angles reduce mod 360.
- **`UNWRITTEN_3D`** `const UNWRITTEN_3D: Readonly<Partial<Record<"x" | "scale" | "y" | "z" | "scaleX" | "scaleY" | "scaleZ" | "opacity" | "anchor" | Turn3d | "custom", string>>>`: The 3D pose fields `applyPose3d` leaves alone, each with the reason; it writes every one.
- **`WRITTEN_3D`** `const WRITTEN_3D: readonly ["x", "y", "z", "rotation", "rotationX", "rotationY", "scale", "scaleX", "scaleY", "scaleZ", "opacity"]`: The 3D pose fields `applyPose3d` writes on an object; custom numbers go to the piece's own writer.
- **`Rest3d`** `type Rest3d = { x: number; y: number; z: number; quaternion: readonly [number, number, number, number]; scale: readonly [number, number, number]; visible: boolean; order: EulerOrder }`: Full rest transform, visibility, and Euler order captured from an `Object3D`.
- **`threeBinder`** `(root: Object3D, options?: ThreeBinderOptions): ThreeBinder`: Binds a scene's object elements to the `Object3D` of the same name under `root`, or to `objects[name]`.
- **`ObjectTarget3d`** `type ObjectTarget3d = Object3D<Object3DEventMap> | readonly Object3D<Object3DEventMap>[] | ((pose: Pose3d, visible: boolean) => void)`: Where a scene's object goes: an `Object3D`, an array of `Object3D`s for a `parts: true` list, or a writer `(pose, visible) => void` such as one handing bone poses to `applyBones`.
- **`ThreeBinder`** `type ThreeBinder = { claims: (name: string) => boolean; start: (player: Player<Readonly<Record<string, unknown>>>, stage: Stage) => () => void; resize?: () => void; counts?: (names?: readonly string[]) => Readonly<Record<string, number>>; measure?: (names?: readonly string[], lists?: ReadonlySet<string>) => Readonly<Record<string, ObjectBounds3d>>; casts?: () => Readonly<Record<string, "single" | "list">> }`: What a mount runs to draw and measure object elements: claims, start, and optional resize, counts, measure, casts.
- **`ThreeBinderOptions`** `type ThreeBinderOptions = { objects?: Readonly<Record<string, ObjectTarget3d>>; resize?: () => void; draw?: () => void }`: Settings of `threeBinder`: target overrides, optional viewport resize callback, and draw callback.
- **`createStage3d`** `(canvas: HTMLCanvasElement, lens: Lens3d, options?: Stage3dOptions): Stage3d`: Wires a Three.js `Scene`, `PerspectiveCamera(lens)`, `WebGLRenderer`, and `threeBinder` with no preset look.
- **`Stage3d`** `type Stage3d = { world: Scene<Object3DEventMap>; camera: PerspectiveCamera; renderer: WebGLRenderer; binder: ThreeBinder; resize: () => void; draw: () => void; dispose: () => void }`: A bare Three.js scene, camera, renderer, and `threeBinder` wired to one `Lens3d`.
- **`Stage3dOptions`** `type Stage3dOptions = { near?: number | undefined; far?: number | undefined; maxPixelRatio?: number | undefined; objects?: Readonly<Record<string, ObjectTarget3d>> | undefined; fallbackSize?: { readonly width: number; readonly height: number; } | undefined }`: Options of `createStage3d`: clipping planes, pixel-ratio cap, object overrides, and fallback size.
- **`useTarget3d`** `<T extends object, K extends Pose3dTargets<T>>(player: Player<T> | undefined, target: K, options?: { readonly invalidate?: () => void; }): RefCallback<Object3D> (+1 overloads)`: Writes a 3D pose target on the object the ref lands on, every step, with no render; its transform then is its rest. With `at`, binds only the `at`th pose of a list target; a missing index writes nothing, a bad one throws.
