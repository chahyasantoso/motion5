# @gerak/rig: ik

- **`SolveQuality`** `type SolveQuality = { readonly kind: "reached"; readonly residual: number; } | { readonly kind: "too-far"; readonly residual: number; } | { readonly kind: "too-near"; readonly residual: number; } | { readonly kind: "coincident"; readonly residual: number; } | { readonly kind: "converged"; readonly iterations: number; readonly residual: number; } | { readonly kind: "stalled"; readonly iterations: number; readonly residual: number; } | { readonly kind: "iteration-cap"; readonly iterations: number; readonly residual: number; } | { readonly kind: "conflicted"; readonly iterations: number; readonly residual: number; } | { readonly kind: "limited"; readonly iterations: number; readonly residual: number; readonly atBound: readonly string[]; }`: How well rotations met the goal: one flat union over both strategies. Residual is distance left; kind says why.
- **`SolveResult`** `type SolveResult<Q> = { rotations: Readonly<Record<string, number>>; residuals: Readonly<Record<string, number>>; quality: Q }`: One IK solve answer, same shape every strategy: rotations plus quality.
- **`UNBOUND_POLE3D`** `const UNBOUND_POLE3D: Pole3d`: Solve with no pole bound; shared, not allocated per solve.
- **`Pole3d`** `type Pole3d = { readonly kind: "unbound"; } | { readonly kind: "point"; readonly point: Vec3; }`: Authored bend control: `unbound` keeps the root-local +z rule; `point` is the world position the elbow bends toward, with the bend plane through pivot, goal and pole.
- **`ChainMember3d`** `type ChainMember3d = { id: string; base: string; length: number; offset: PivotOffset3d; rest: Euler3d; limit?: JointLimit3d; influence?: number; orient?: number; goal?: WorldFrame3d }`: One member of a 3D solver chain, as both 3D strategies read it. `base` names parent or root; `limit`, `influence`, `orient`, `goal` only where authored; absent = free or unpulled.
- **`FREE_JOINT3D`** `const FREE_JOINT3D: JointLimit3d`: The joint limit that constrains nothing; shared, not allocated per read.
- **`JointLimit3d`** `type JointLimit3d = { readonly kind: "free"; } | { readonly kind: "hinge"; readonly axis: Vec3; readonly range: JointLimit; } | { readonly kind: "cone"; readonly maxSwing: number; } | { readonly kind: "swing-twist"; readonly maxSwing: number; readonly twist: JointLimit; }`: Sole owner of 3D joint limits: the legal local orientation, relative to the parent's solved frame, nearest the one the solve proposes.
- **`chainShape3d`** `(members: readonly ChainMember3d[]): ChainShape3d`: Chain shape, or a throw when no member carries a goal. Order: goal guard → `constrained` → `two-bone` pair → `tree`.
- **`solveChain3d`** `(root: WorldFrame3d, members: readonly ChainMember3d[], bend?: Pole3d): SolveResult3d`: Solves one 3D chain: position by shape, then each oriented leaf toward its goal. Orientation turns leaves without moving the tip, so position keeps priority.
- **`ChainShape3d`** `type ChainShape3d = { readonly kind: "two-bone"; readonly first: ChainMember3d; readonly second: ChainMember3d; readonly goal: WorldFrame3d; } | { readonly kind: "tree"; readonly members: readonly ChainMember3d[]; } | { readonly kind: "constrained"; readonly members: readonly ChainMember3d[]; }`: Strategy answering one 3D chain; derived at solve time, never authored. `two-bone` carries pair + goal, `tree` members, `constrained` members with a limiting joint.
