# @gerak/dom: index

- **`applyPath`** `(target: RenderTarget, cubics: readonly Cubic2d[]): void`: Sets a path element's `d` to the cubic segments.
- **`applyValue`** `(target: RenderTarget, value: Pose2d, length?: number): void`: Writes a value, each custom number as `--<name>`; an unmeasured stroke is left undashed. A value equal to the last one written to that style, at that length, writes nothing.
- **`cssClip`** `(x: number, y: number, radius: number): string`: A CSS clip path showing what lies inside a circle `radius` px round, centred `x`, `y` px from the top left.
- **`cssDash`** `(from: number, to: number, length: number): { readonly strokeDasharray: string; readonly strokeDashoffset: number; }`: The stroke dash that shows the stretch from share `from` to share `to` of a path `length` long.
- **`cssOrigin`** `(anchor: Anchor): string`: The CSS transform origin an anchor names.
- **`cssTransform`** `(values: Readonly<Record<string, unknown>>): string`: A CSS transform from pose-like values: translate first, then turns, then skews, then scales; empty when nothing moves.
- **`pathData`** `(cubics: readonly Cubic2d[]): string`: SVG path data for joined cubic segments.
- **`TRANSFORM_KEYS`** `const TRANSFORM_KEYS: readonly string[]`: The value keys a CSS transform carries; every other key writes as its own property.
- **`UNWRITTEN`** `const UNWRITTEN: Readonly<Partial<Record<CarriedBy<"both" | "2d"> | CarriedBy<"3d"> | "anchor" | "custom", string>>>`: The pose fields `@gerak/dom` leaves alone, each with the reason; it writes every one today.
- **`WRITTEN`** `const WRITTEN: readonly (CarriedBy<"both" | "2d"> | CarriedBy<"3d"> | "anchor" | "custom")[]`: The pose fields `@gerak/dom` writes: `applyValue` to an element's style, and the stage a path member's `shape` as its outline; custom numbers are written apart, as `--<name>` properties.
- **`RenderStyle`** `type RenderStyle = { transform?: string; zIndex?: string; transformOrigin?: string; transformBox?: string; opacity?: string; filter?: string; clipPath?: string; strokeDasharray?: string; strokeDashoffset?: string; visibility?: string; setProperty?: (name: string, value: string) => void; removeProperty?: (name: string) => void }`: The style properties a renderer writes; a real element's `CSSStyleDeclaration` has them all.
- **`RenderTarget`** `type RenderTarget = { style: RenderStyle; setAttribute?: (name: string, value: string) => void; getTotalLength?: () => number; ownerSVGElement?: unknown }`: An element a renderer writes: its style, and the attribute and measuring hooks an SVG element has.
- **`clockDriver`** `(options: ClockOptions): ClockDriver`: A timed clock on the page's frames. Under reduced motion it shows the last frame and never ticks until `.play()`; `reducedMotion: "play"` opts out.
- **`scrollDriver`** `(options: { readonly target?: ScrollTarget; readonly start: number; readonly end: number; readonly length?: number; }): Driver`: A driver from 0 to 1 as the target scrolls from `start` to `end` px; untimed unless given a `length` in ms.
- **`ClockDriver`** `type ClockDriver = { play: () => void; pause: () => void; seek: (progress: number) => void; replay: () => void; dispose: () => void; setRate: (rate: number) => void; setRange: (fromMs?: number, toMs?: number) => void; playing: () => boolean; watch: (target: string, element: EventSource) => () => void; send: (name: string, value: number, target?: string) => void; events: () => Events; forgets: (listener: () => void) => () => void; now: () => Time; subscribe: (listener: () => void) => () => void; options?: object }`: A driver on the page's frames, timed in ms, with the delay, repeat and yoyo a `time` trigger has.
- **`ClockOptions`** `type ClockOptions = { duration: number; delay?: number; repeat?: number; yoyo?: boolean; autoplay?: boolean; frames?: FrameSource; reducedMotion?: "end" | "play"; prefersReducedMotion?: () => boolean }`: Settings of `clockDriver`: `duration` ms, `delay`, `repeat`, `yoyo`, `autoplay`, `frames` and `reducedMotion`.
- **`ScrollTarget`** `type ScrollTarget = { scrollY?: number; scrollTop?: number; addEventListener: (type: "scroll", listener: () => void) => void; removeEventListener: (type: "scroll", listener: () => void) => void }`: What a scroll driver reads: a window or a scrolling element.
- **`FrameSource`** `type FrameSource = { requestFrame: (listener: (time: number) => void) => number; cancelFrame: (handle: number) => void }`: Where frames come from: `requestAnimationFrame` on a page, a fake one in a test.
- **`eventDriver`** `(options?: EventDriverOptions): EventDriver`: A live clock that logs events: `.watch`, `.watchView` and `.emit`. `introMs` keeps frames coming for an intro, `settleMs` after the last event.
- **`WATCHED`** `const WATCHED: Readonly<Record<string, string>>`: The page events a watched element turns into motion events, and the name each gets.
- **`EventDriver`** `type EventDriver = { watch: (target: string, element: EventSource) => () => void; watchView: (target: string, element: Element, threshold?: number) => () => void; emit: (name: string, target?: string, point?: Point2d) => void; dispose: () => void; now: () => Time; events?: () => Events; subscribe: (listener: () => void) => () => void; options?: object }`: A live driver: its clock runs from creation, and it logs the events of the elements it watches.
- **`EventDriverOptions`** `type EventDriverOptions = { settleMs?: number; introMs?: number; frames?: FrameSource; clock?: () => number }`: Settings of `eventDriver`: `settleMs` (default 2000 ms), `introMs` (0), `frames` and `clock`.
- **`EventSource`** `type EventSource = { addEventListener: (type: string, listener: (event: PointerLike) => void) => void; removeEventListener: (type: string, listener: (event: PointerLike) => void) => void; getBoundingClientRect?: () => { readonly left: number; readonly top: number; } }`: Something that sends DOM events: an element, or a stand-in in a test.
- **`PointerLike`** `type PointerLike = { clientX?: number; clientY?: number }`: What a pointer event says about where it happened.
- **`BINDER_CASTS`** `const BINDER_CASTS: typeof BINDER_CASTS`: Global registry where mounts publish binder-discovered cast names even if scene validation fails.
- **`mount`** `(input: StageInput, options: MountOptions): Mounted`: Plays a scene over the cast its markup tags `data-cast`, on a live or timed clock, in place or fitted to its frame.
- **`Binder`** `type Binder = { claims: (name: string) => boolean; start: (player: Player<StageValues>, stage: Stage) => () => void; resize?: () => void; counts?: (names?: readonly string[]) => Readonly<Record<string, number>>; measure?: (names?: readonly string[], lists?: ReadonlySet<string>) => Readonly<Record<string, ObjectBounds3d>>; casts?: () => Readonly<Record<string, BinderCastKind>> }`: What draws a scene's object elements beside the mount: claims, lifecycle start, optional resize, counts, measure, casts.
- **`BinderCastKind`** `type BinderCastKind = "list" | "single"`: Whether a bound cast target is a single element/object or a multi-part list.
- **`MOUNTS`** `const MOUNTS: typeof MOUNTS`: Where every live mount on a page is listed, for the page tools that read what it measured.
- **`MeasuredBox`** `type MeasuredBox = { x: number; y: number; width: number; height: number; placement: BoxPlacement }`: A rest box as a measure holds it: its centre and size in px, and how the page places it.
- **`Measurement`** `type Measurement = { frame: { readonly width: number; readonly height: number; }; rest: Readonly<Record<string, MeasuredBox>>; lines: Readonly<Record<string, readonly number[]>>; parents: Readonly<Record<string, string>>; objects?: Readonly<Record<string, ObjectBounds3d>>; counts?: Readonly<Record<string, number>> }`: What a mount measured, as plain data: frame, rest boxes, split lines, parents, 3D sizes and 3D list counts.
- **`Mounted`** `type Mounted = { player: Player<Readonly<Record<string, unknown>>>; driver: Driver; durationMs: number | undefined; rest: Readonly<Record<string, Box>>; lines: Readonly<Record<string, readonly number[]>>; remeasure: () => void; measure: () => Measurement; replace: (next: StageInput) => void; send: (name: string, value: number, target?: string) => void; events: () => Events; settled: () => Promise<void>; media: () => readonly { readonly name: string; readonly clipMs: number | undefined; readonly from: number; readonly to: number; }[]; dispose: () => void }`: A playing mount: its player, driver, measured rests and text lines, input logger, and cleanup.
- **`MountClock`** `type MountClock = "timed" | "live" | { readonly kind: "driver"; readonly driver: Driver; }`: What a mount's time is: `"live"` runs on from mount, read by scroll, pointer and triggers; `"timed"` runs over the scene's length and seeks, for reels and capture.
- **`MountFrame`** `type MountFrame = "page" | "fit"`: Where a mount draws: `"page"` in place, or `"fit"`, scaling `root` about its top left to fit its parent (or the viewport for `body`, `html`, or an unsized parent).
- **`MountOptions`** `type MountOptions = { clock: MountClock; frame?: MountFrame; root?: PageRoot; scrollTarget?: PageScrollTarget; frames?: FrameSource; settleMs?: number; now?: () => number; viewport?: () => { readonly width: number; readonly height: number; }; onDriver?: (driver: Driver) => void; checks?: boolean; nodes?: Readonly<Record<string, PageElement | readonly PageElement[]>>; binders?: readonly Binder[] }`: Settings of `mount`: its clock and frame, the root it binds in, and the hooks tests and tools use.
- **`StageEvent`** `type StageEvent = { key?: string; target?: unknown; clientX?: number; clientY?: number }`: What a mount reads of a page event: a key, where it landed, and the element it landed on.
- **`StageFonts`** `type StageFonts = { ready: Promise<unknown>; addEventListener: (type: "loadingdone", listener: () => void) => void; removeEventListener: (type: "loadingdone", listener: () => void) => void }`: The document's font loading, which tells a mount when text may have changed size.
- **`StageInput`** `type StageInput = Scene | Stage`: What `mount` and `<Stage>` take: a compiled stage, or what `scene` returns.
- **`StageValues`** `type StageValues = { readonly [x: string]: unknown; }`: A frame's targets as the scene returned them: a pose per actor or object, a function per list.
- **`PageElement`** `type PageElement = { style: PageStyle; textContent: string | null; children?: ArrayLike<unknown>; childNodes?: ArrayLike<unknown>; parentElement?: unknown; ownerDocument?: unknown; offsetLeft?: number; offsetTop?: number; offsetWidth?: number; offsetHeight?: number; getBoundingClientRect?: () => { readonly left: number; readonly top: number; readonly right?: number; readonly bottom?: number; readonly width: number; readonly height: number; }; setAttribute?: (name: string, value: string) => void; removeAttribute?: (name: string) => void; getTotalLength?: () => number; append?: (...nodes: unknown[]) => void; replaceChildren?: (...nodes: unknown[]) => void; addEventListener: (type: string, listener: (event: StageEvent) => void) => void; removeEventListener: (type: string, listener: (event: StageEvent) => void) => void; ownerSVGElement?: unknown }`: Minimal contract of a page DOM node animated by `mount`, real element or test double.
- **`PageRoot`** `type PageRoot = { querySelector: (selector: string) => unknown; querySelectorAll: (selector: string) => ArrayLike<unknown>; ownerDocument?: unknown; defaultView?: unknown; fonts?: StageFonts; documentElement?: unknown; body?: unknown; addEventListener?: (type: string, listener: (event: StageEvent) => void, options?: { readonly passive?: boolean; }) => void; removeEventListener?: (type: string, listener: (event: StageEvent) => void) => void }`: Container queried by `mount` to bind the cast and listen for viewport pointer motion.
- **`PageScrollTarget`** `type PageScrollTarget = { scrollY?: number; scrollX?: number; scrollTop?: number; scrollLeft?: number; innerWidth?: number; innerHeight?: number; addEventListener: (type: string, listener: () => void, options?: { readonly passive?: boolean; }) => void; removeEventListener: (type: string, listener: () => void) => void }`: What a page mount reads vertical and horizontal scroll offsets from.
- **`PageStyle`** `type PageStyle = { display?: string; position?: string; top?: string; right?: string; bottom?: string; left?: string; whiteSpace?: string; transform?: string; zIndex?: string; transformOrigin?: string; transformBox?: string; opacity?: string; filter?: string; clipPath?: string; strokeDasharray?: string; strokeDashoffset?: string; visibility?: string; setProperty?: (name: string, value: string) => void; removeProperty?: (name: string) => void }`: The style properties written or cleared while measuring and animating an existing page node.
- **`ready`** `<T>(promise: PromiseLike<T>): Promise<void>`: Registers `promise` on `window.__motionReady` for page readiness waits and settles to void.
