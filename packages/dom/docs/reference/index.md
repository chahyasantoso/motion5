# @gerak/dom: index

- **`applyPath`** `(target: RenderTarget, cubics: readonly Cubic2d[]): void`: Sets a path element's `d` to the cubic segments.
- **`applyValue`** `(target: RenderTarget, value: Pose2d, length?: number): void`: Writes a value, each custom number as `--<name>`; a stroke with no length to measure is left undashed.
- **`cssClip`** `(x: number, y: number, radius: number): string`: A CSS clip path showing what lies inside a circle `radius` px round, centred `x`, `y` px from the top left.
- **`cssDash`** `(from: number, to: number, length: number): { readonly strokeDasharray: string; readonly strokeDashoffset: number; }`: The stroke dash that shows the stretch from share `from` to share `to` of a path `length` long.
- **`cssOrigin`** `(anchor: Anchor): string`: The CSS transform origin an anchor names.
- **`cssTransform`** `(values: Readonly<Record<string, unknown>>): string`: A CSS transform from pose-like values: translate first, then turns, then skews, then scales; empty when nothing moves.
- **`pathData`** `(cubics: readonly Cubic2d[]): string`: SVG path data for joined cubic segments.
- **`TRANSFORM_KEYS`** `const TRANSFORM_KEYS: readonly string[]`: The value keys a CSS transform carries; every other key writes as its own property.
- **`UNWRITTEN`** `const UNWRITTEN: Readonly<Partial<Record<CarriedBy<"both" | "2d"> | "anchor" | "custom", string>>>`: The pose fields `@gerak/dom` leaves alone, each with the reason; it writes every one today.
- **`WRITTEN`** `const WRITTEN: readonly (CarriedBy<"both" | "2d"> | "anchor" | "custom")[]`: The pose fields `@gerak/dom` writes: `applyValue` to an element's style, and the stage a path member's `shape` as its outline; custom numbers are written apart, as `--<name>` properties.
- **`RenderStyle`** `type RenderStyle = { transform?: string; zIndex?: string; transformOrigin?: string; transformBox?: string; opacity?: string; filter?: string; clipPath?: string; strokeDasharray?: string; strokeDashoffset?: string; visibility?: string; setProperty?: (name: string, value: string) => void; removeProperty?: (name: string) => void }`: The style properties a renderer writes; a real element's `CSSStyleDeclaration` has them all.
- **`RenderTarget`** `type RenderTarget = { style: RenderStyle; setAttribute?: (name: string, value: string) => void; getTotalLength?: () => number; ownerSVGElement?: unknown }`: An element a renderer writes: its style, and the attribute and measuring hooks an SVG element has.
- **`clockDriver`** `(options: ClockOptions): ClockDriver`: A timed clock on the page's frames. Under reduced motion it shows the last frame and never ticks until `.play()`; `reducedMotion: "play"` opts out.
- **`scrollDriver`** `(options: { readonly target?: ScrollTarget; readonly start: number; readonly end: number; readonly length?: number; }): Driver`: A driver from 0 to 1 as the target scrolls from `start` to `end` px; untimed unless given a `length` in ms.
- **`ClockDriver`** `type ClockDriver = { play: () => void; pause: () => void; seek: (progress: number) => void; replay: () => void; dispose: () => void; setRate: (rate: number) => void; setRange: (fromMs?: number, toMs?: number) => void; playing: () => boolean; watch: (target: string, element: EventSource) => () => void; send: (name: string, value: number, target?: string) => void; events: () => Events; now: () => Time; subscribe: (listener: () => void) => () => void; options?: object }`: A driver on the page's frames, timed in ms, with the delay, repeat and yoyo a `time` trigger has.
- **`ClockOptions`** `type ClockOptions = { duration: number; delay?: number; repeat?: number; yoyo?: boolean; autoplay?: boolean; frames?: FrameSource; reducedMotion?: "end" | "play"; prefersReducedMotion?: () => boolean }`: Settings of `clockDriver`: `duration` ms, `delay`, `repeat`, `yoyo`, `autoplay`, `frames` and `reducedMotion`.
- **`ScrollTarget`** `type ScrollTarget = { scrollY?: number; scrollTop?: number; addEventListener: (type: "scroll", listener: () => void) => void; removeEventListener: (type: "scroll", listener: () => void) => void }`: What a scroll driver reads: a window or a scrolling element.
- **`FrameSource`** `type FrameSource = { requestFrame: (listener: (time: number) => void) => number; cancelFrame: (handle: number) => void }`: Where frames come from: `requestAnimationFrame` on a page, a fake one in a test.
- **`eventDriver`** `(options?: EventDriverOptions): EventDriver`: A live clock that logs events: `.watch`, `.watchView` and `.emit`. `introMs` keeps frames coming for an intro, `settleMs` after the last event.
- **`WATCHED`** `const WATCHED: Readonly<Record<string, string>>`: The page events a watched element turns into motion events, and the name each gets.
- **`EventDriver`** `type EventDriver = { watch: (target: string, element: EventSource) => () => void; watchView: (target: string, element: Element, threshold?: number) => () => void; emit: (name: string, target?: string, point?: { readonly x: number; readonly y: number; }) => void; dispose: () => void; now: () => Time; events?: () => Events; subscribe: (listener: () => void) => () => void; options?: object }`: A live driver: its clock runs from creation, and it logs the events of the elements it watches.
- **`EventDriverOptions`** `type EventDriverOptions = { settleMs?: number; introMs?: number; frames?: FrameSource; clock?: () => number }`: Settings of `eventDriver`: `settleMs` (default 2000 ms), `introMs` (0), `frames` and `clock`.
- **`EventSource`** `type EventSource = { addEventListener: (type: string, listener: (event: PointerLike) => void) => void; removeEventListener: (type: string, listener: (event: PointerLike) => void) => void; getBoundingClientRect?: () => { readonly left: number; readonly top: number; } }`: Something that sends DOM events: an element, or a stand-in in a test.
- **`PointerLike`** `type PointerLike = { clientX?: number; clientY?: number }`: What a pointer event says about where it happened.
- **`mountStage`** `<B extends string>(container: HTMLElement, module: StageModule<B, StageValues>, options?: StageOptions): MountedStage<B> (+1 overloads)`: Plays a stage module in `container`: builds its cast, scopes its skin, fits its frame, measures each rest box and binds the scene's values; `R` or a click on the background replays it.
- **`stageModuleOf`** `<B extends string>(module: StageModule<B>): StageModule<B, StageValues>`: A stage module whose scene answers any object, checked on every frame to be stage values.
- **`MountedStage`** `type MountedStage<B> = { player: Player<Readonly<Record<string, Pose2d | readonly Pose2d[] | undefined>>>; driver: ClockDriver; replay: () => void; replace: (next: StageModule<B, StageValues>) => void; send: (name: string, value: number, target?: string) => void; events: () => Events; dispose: () => void }`: A playing stage: its player and driver, which a replay swaps for fresh ones.
- **`StageElement`** `type StageElement<E, S> = { style: StageStyle; textContent: string | null; tabIndex: number; offsetLeft: number; clientLeft: number; clientTop: number; offsetTop: number; offsetWidth: number; offsetHeight: number; clientWidth: number; clientHeight: number; ownerDocument: { createElement(tag: "div" | "style"): E; createElementNS(namespace: typeof SVG, name: "svg" | "path"): S; readonly fonts?: StageFonts; }; attachShadow: (init: { readonly mode: "open"; }) => { append(...nodes: E[]): void; }; setAttribute: (name: string, value: string) => void; removeAttribute: (name: string) => void; append: (...nodes: (E | S)[]) => void; remove: () => void; addEventListener: (type: string, listener: (event: StageEvent) => void) => void; removeEventListener: (type: string, listener: (event: StageEvent) => void) => void }`: An element the stage builds with and writes: a page element, or a stand-in in a test; `S` is the SVG element it draws a stroke member's path with.
- **`StageEvent`** `type StageEvent = { key?: string; target?: unknown; clientX?: number; clientY?: number }`: What the stage reads of a page event: a key, where it landed, and the element it landed on.
- **`StageFonts`** `type StageFonts = { ready: Promise<unknown>; addEventListener: (type: "loadingdone", listener: () => void) => void; removeEventListener: (type: "loadingdone", listener: () => void) => void }`: The document's font loading, which tells the stage when text may have changed size.
- **`StageOptions`** `type StageOptions = { frames?: FrameSource; onDriver?: (driver: ClockDriver) => void }`: Settings of `mountStage`: the frames its clock runs on.
- **`StageStyle`** `type StageStyle = { visibility?: string; display?: string; position?: string; overflow?: string; left?: string; top?: string; marginLeft?: string; marginTop?: string; width?: string; height?: string; aspectRatio?: string; transform?: string; zIndex?: string; transformOrigin?: string; transformBox?: string; opacity?: string; filter?: string; clipPath?: string; strokeDasharray?: string; strokeDashoffset?: string; setProperty?: (name: string, value: string) => void; removeProperty?: (name: string) => void }`: The style properties the stage writes beside a value's; a page element's style has them all.
- **`StageValues`** `type StageValues = { readonly [x: string]: Pose2d | readonly Pose2d[] | undefined; }`: A scene's answer per member name: one value, or one per item of a `many`.
