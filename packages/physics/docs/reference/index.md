# @gerak/physics: index

- **`builtinWorld`** `(): PhysicsWorld`: The built-in engine: circles and boxes that turn, on floors, walls and segments; pure and synchronous.
- **`simulate`** `(world: PhysicsWorld, build: (world: PhysicsWorld) => void, options?: SimulateOptions): Simulation (+1 overloads)`: Builds a world once with `build`, then steps it at a fixed `dt`, spawning on events, as far as each question asks. Builds a 3D world once with `build`, then steps it at a fixed `dt`, spawning on events, as far as each question asks.
- **`Placed`** `type Placed = { x: number; y: number; rotation: number; opacity: number }`: Where a body is for an element laid out centred on the stage's top left corner, and whether it exists yet.
- **`SimulateOptions`** `type SimulateOptions = { dt?: number; checkpointMs?: number; durationMs?: number; maxCheckpoints?: number; spawn?: (event: MotionEvent, world: Spawner) => void }`: Settings of `simulate`: `dt` seconds a step (default 1/120), `checkpointMs` (250), `maxCheckpoints` (32), `durationMs` (0) and `spawn`.
- **`SimulateOptions3d`** `type SimulateOptions3d = { dt?: number; checkpointMs?: number; durationMs?: number; maxCheckpoints?: number; spawn?: (event: MotionEvent, world: Spawner3d) => void }`: Settings of 3D `simulate`: `dt` seconds a step (default 1/120), `checkpointMs` (250), `maxCheckpoints` (32), `durationMs` (0) and `spawn`.
- **`Simulation`** `type Simulation = { at: (time: Time, events?: Events) => Readonly<Record<string, BodyState>>; bodies: (time: Time, events?: Events) => readonly string[]; pose: (id: string, time: Time, events?: Events) => { readonly x: number; readonly y: number; readonly rotation: number; }; place: (id: string, time: Time, events?: Events) => Placed; events: (time: Time, events?: Events) => Events }`: A world played from time 0, seekable to any time, the same at the same time and events whatever came before.
- **`Simulation3d`** `type Simulation3d = { at: (time: Time, events?: Events) => Readonly<Record<string, BodyState3d>>; bodies: (time: Time, events?: Events) => readonly string[]; pose: (id: string, time: Time, events?: Events) => { readonly x: number; readonly y: number; readonly z: number; readonly rotation: Quaternion3d; }; events: (time: Time, events?: Events) => Events }`: A 3D world played from time 0, seekable to any time, deterministic across seeks.
- **`Spawner`** `type Spawner = { addBody: (body: BodySpec) => void }`: What a spawn may do to the world: add bodies, nothing else.
- **`Spawner3d`** `type Spawner3d = { addBody: (body: BodySpec3d) => void }`: What a 3D spawn may do to the world: add 3D bodies, nothing else.
- **`BodySpec`** `type BodySpec = { id: string; shape: Shape; x: number; y: number; vx?: number; vy?: number; angle?: number; spin?: number; fixedRotation?: boolean; drag?: number; mass?: number; restitution?: number; friction?: number }`: A body to add: where its centre starts in stage px, its turn in degrees, and how fast both change.
- **`BodySpec3d`** `type BodySpec3d = { id: string; shape: Shape3d; x: number; y: number; z: number; vx?: number; vy?: number; vz?: number; rotation?: Quaternion3d; wx?: number; wy?: number; wz?: number; fixedRotation?: boolean; drag?: number; mass?: number; restitution?: number; friction?: number }`: A 3D body to add: starting position in world units, initial quaternion, and velocities (degrees/s).
- **`BodyState`** `type BodyState = { x: number; y: number; rotation: number; vx: number; vy: number; spin: number }`: Where a body's centre is in stage px and how it is turned in degrees, and how fast each changes a second.
- **`BodyState3d`** `type BodyState3d = { x: number; y: number; z: number; rotation: Quaternion3d; vx: number; vy: number; vz: number; wx: number; wy: number; wz: number }`: A 3D body's world position, orientation quaternion, linear velocity, and angular velocity (deg/s).
- **`Collider`** `type Collider = { readonly kind: "floor"; readonly y: number; } | { readonly kind: "wall"; readonly x: number; readonly side: "left" | "right"; } | { readonly kind: "segment"; readonly from: { readonly x: number; readonly y: number; }; readonly to: { readonly x: number; readonly y: number; }; }`: A collider that never moves: the line bodies rest on, a side that keeps them in, or a ramp.
- **`Collider3d`** `type Collider3d = { readonly kind: "floor"; readonly y: number; } | { readonly kind: "wall"; readonly axis: "x" | "z"; readonly at: number; readonly side: "min" | "max"; } | { readonly kind: "box"; readonly x: number; readonly y: number; readonly z: number; readonly width: number; readonly height: number; readonly depth: number; }`: A fixed 3D collider: a horizontal floor at `y`, an `x`/`z` boundary wall, or a static box.
- **`Contact`** `type Contact = { a: string; b: string; x: number; y: number }`: Two things that started touching during a step, and where: body ids, or a body id and a collider id, and the point in stage px.
- **`Contact3d`** `type Contact3d = { z: number; a: string; b: string; x: number; y: number }`: A 3D contact: the pair that started touching and the point where they met, in scene units.
- **`PhysicsWorld`** `type PhysicsWorld = { addBody: (body: BodySpec) => void; addCollider: (id: string, collider: Collider, surface?: Surface) => void; setGravity: (x: number, y: number) => void; step: (seconds: number) => void; body: (id: string) => BodyState; drainContacts: () => readonly Contact[]; snapshot: () => Uint8Array; restore: (snapshot: Uint8Array) => void }`: What every physics engine gives a scene, in stage px, degrees and seconds, y down and turns clockwise.
- **`PhysicsWorld3d`** `type PhysicsWorld3d = { addBody: (body: BodySpec3d) => void; addCollider: (id: string, collider: Collider3d, surface?: Surface) => void; setGravity: (x: number, y: number, z: number) => void; step: (seconds: number) => void; body: (id: string) => BodyState3d; drainContacts: () => readonly Contact3d[]; snapshot: () => Uint8Array; restore: (snapshot: Uint8Array) => void }`: What a 3D physics engine gives a scene: world units, y up, quaternions and degrees a second.
- **`Quaternion3d`** `type Quaternion3d = { w: number; x: number; y: number; z: number }`: A unit quaternion `{ w, x, y, z }` representing a 3D orientation.
- **`Shape`** `type Shape = { readonly kind: "circle"; readonly radius: number; } | { readonly kind: "box"; readonly width: number; readonly height: number; }`: A body's outline: a circle by its radius, or a box by its size, centred on the body.
- **`Shape3d`** `type Shape3d = { readonly kind: "sphere"; readonly radius: number; } | { readonly kind: "box"; readonly width: number; readonly height: number; readonly depth: number; }`: A 3D body's shape: a sphere by radius, or a box by width, height and depth, centred on the body.
- **`Surface`** `type Surface = { restitution?: number; friction?: number }`: How a surface answers a hit: bounce kept, from 0 to 1, and grip, from 0 up; the two sides' values average.
