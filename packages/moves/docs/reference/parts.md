# @gerak/moves: parts

- **`definePart`** `<F extends object>(contract: PartContract, fn: F): F`: Declares what a part promises and returns the part itself, unchanged; the part gate refuses a part with no declaration, or one whose samples break the rule of its kind.
- **`partContract`** `(fn: object): PartContract | undefined`: The contract `definePart` recorded for a part, or nothing when it was never declared.
- **`PartContract`** `type PartContract = { readonly kind: "time"; } | { readonly kind: "geometry"; } | { readonly kind: "signal"; } | { readonly kind: "utility"; } | { readonly kind: "ease"; readonly samples: readonly (Labelled & { readonly run: (progress: number) => number; })[]; } | { readonly kind: "envelope"; readonly samples: readonly (Labelled & { readonly run: (progress: number) => number; readonly at0: number; readonly at1: number; })[]; } | { readonly kind: "oscillation"; readonly samples: readonly (Labelled & { readonly run: (progress: number) => number; readonly bound: number; })[]; } | { readonly kind: "dynamics"; readonly samples: readonly (Labelled & { readonly run: (seconds: number) => { readonly offset: number; readonly speed: number; }; })[]; } | { readonly kind: "path"; readonly samples: readonly (Labelled & { readonly run: (progress: number) => Numbers; readonly from: Numbers; readonly to: Numbers; })[]; } | { readonly kind: "blend"; readonly samples: readonly (Labelled & { readonly run: (share: number) => unknown; readonly a: unknown; readonly b: unknown; readonly angle?: true; })[]; } | { readonly kind: "coupling"; readonly samples: readonly (Labelled & { readonly run: () => unknown; })[]; }`: What a part promises, by the folder it lives in; each sampled kind carries closures the part gate runs.
- **`noise1d`** `(seed: number, scale?: number): (ms: number) => number`: A smooth wandering value from -1 to 1 over time in ms, easing to a fresh seeded target every `scale` ms; the same seed wanders the same.
- **`follow`** `(options: FollowOptions): (time: Time, events: Events) => number`: A spring each named event sends towards its goal, or a sample's own with `"value"`, turning back with no jump; pure in time and events, a later call goes on from the last.
- **`react`** `(options: ReactOptions): (time: Time, events: Events) => number`: A damped answer to each past event by `kind` (`recoil`, `wobble`, `flash` or `shake`); 0 before the first and once all have died.
- **`FollowOptions`** `type FollowOptions = { start: number; on: Readonly<Record<string, number | "value">>; target?: string; stiffness?: number; damping?: number; rest?: number }`: Settings of a `follow`: `start`, `on` (goal by event name, or `"value"` for the event's own), `target`, `stiffness` (default 170), `damping` (26) and `rest` (0.001).
- **`ReactionKind`** `type ReactionKind = "recoil" | "wobble" | "flash" | "shake"`: How a response to one event moves: from a full start, from rest, as a fade, or as a shake.
- **`ReactOptions`** `type ReactOptions = { on: readonly string[]; target?: string; kind: ReactionKind; amplitude: number; decay?: number; frequency?: number }`: Settings of a `react`: event names `on`, `target`, `kind`, `amplitude`, `decay` (default 6 a second) and `frequency` (4 a second).
- **`squashed`** `(squash: number, weight: number, anchor?: Anchor): Pose2d`: A pose `weight` of the way into `squash` against the `anchor` side, `"bottom"` when absent; `"left"` and `"right"` squash sideways.
- **`squashed3d`** `(squash: number, weight: number, axis?: "x" | "y" | "z"): Pose3d`: A body `weight` of the way into its `squash` along `axis`, widened on the other two so its volume stays.
