# @gerak/moves: style

- **`defineStyle`** `(card: StyleCard): StyleCard`: A frozen copy of the card, or an error naming its first problem.
- **`isStyleCard`** `(value: unknown): value is StyleCard`: Whether `value` is a card `defineStyle` returned itself.
- **`StyleCard`** `type StyleCard = { name: string; description: string; qualities: { readonly [x: string]: DescriptorRanges; }; lively: { readonly x?: readonly [number, number]; readonly scale?: readonly [number, number]; readonly y?: readonly [number, number]; readonly z?: readonly [number, number]; readonly rotation?: readonly [number, number]; readonly rotationX?: readonly [number, number]; readonly rotationY?: readonly [number, number]; readonly skewX?: readonly [number, number]; readonly skewY?: readonly [number, number]; readonly scaleX?: readonly [number, number]; readonly scaleY?: readonly [number, number]; readonly scaleZ?: readonly [number, number]; readonly opacity?: readonly [number, number]; readonly blur?: readonly [number, number]; readonly shadowX?: readonly [number, number]; readonly shadowY?: readonly [number, number]; readonly shadowBlur?: readonly [number, number]; readonly hue?: readonly [number, number]; readonly lightness?: readonly [number, number]; readonly tint?: readonly [number, number]; readonly drawn?: readonly [number, number]; readonly drawnFrom?: readonly [number, number]; readonly clipX?: readonly [number, number]; readonly clipY?: readonly [number, number]; readonly clipRadius?: readonly [number, number]; readonly clipWidth?: readonly [number, number]; readonly clipHeight?: readonly [number, number]; readonly shape?: readonly [number, number]; readonly layer?: readonly [number, number]; }; tokens: { readonly [x: string]: string; }; habits: readonly string[] }`: A brief's style: the qualities it names, the share of lively motion each field holds, and its tokens and habits.
- **`DESCRIPTOR_KEYS`** `const DESCRIPTOR_KEYS: readonly ["peak", "overshoot", "rings", "windup", "settle"]`: The descriptors a quality may range over, in the order every report lists them.
- **`QUALITIES`** `const QUALITIES: { readonly [x: string]: DescriptorRanges; }`: The words `--like` understands, each as the ranges of descriptors a move with that quality sits in; `drop` measures heavy, `fade` calm, `pop` playful and `jolt` loose.
- **`isLively`** `(shape: Descriptors): boolean`: Whether a shape is lively: it overshoots, rings or winds up.
- **`outsideRanges`** `(descriptors: Descriptors, ranges: DescriptorRanges): readonly { readonly key: "overshoot" | "peak" | "settle" | "rings" | "windup"; readonly value: number; readonly range: readonly [number, number]; }[]`: The descriptors a quality names that lie outside its range, each with its value and range; none means the shape has the quality.
- **`qualityOf`** `(name: string): DescriptorRanges | undefined`: A quality's ranges by name, or none for a name `QUALITIES` does not hold itself (`toString` included).
- **`DescriptorRanges`** `type DescriptorRanges = { peak?: readonly [number, number] | undefined; overshoot?: readonly [number, number] | undefined; rings?: readonly [number, number] | undefined; windup?: readonly [number, number] | undefined; settle?: readonly [number, number] | undefined }`: The qualities `--like` knows, as a range per descriptor: `rings` counts, the others are shares or ratios.
- **`Descriptors`** `type Descriptors = { travelling: boolean; peak: number; overshoot: number; rings: number; windup: number; settle: number }`: How one field's offset from rest moves over a move's progress.
