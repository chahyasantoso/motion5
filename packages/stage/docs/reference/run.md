# @gerak/stage: run

What renderers and tools run a piece with: `compileScene`'s `Stage`, `frame` and `check`, and the closed `StageError`. Reach for it when you run, test or review a piece.

- **`isStage`** `(value: unknown): value is Stage`: Whether `value` reads as a compiled stage: `kind` only, so a stage from a second copy of the package passes.
- **`CompileResult`** `type CompileResult = { readonly ok: true; readonly stage: Stage; } | { readonly ok: false; readonly errors: readonly StageError[]; }`: A compiled stage or every reason it is not one.
- **`Member`** `type Member = { readonly name: string; readonly expect: Expect; readonly watch: boolean; readonly node?: string | undefined; readonly on?: readonly Window[] | undefined; readonly onScroll?: readonly ScrollWindow[] | undefined; } & ({ readonly kind: "object"; readonly parts?: boolean | undefined; } | { readonly kind: "actor"; readonly content: Content; } | { readonly kind: "list"; readonly split?: "letters" | "words" | undefined; })`: One compiled member; list items are named `<list>.<index>`.
- **`Stage`** `type Stage = { kind: "stage"; durationMs: number; beats: Readonly<Record<string, Span>>; members: readonly Member[]; cues: Events; limits: Readonly<Record<string, Limits>>; settleMs?: number | undefined; shots?: readonly ShotSummary[] | undefined; scene: (context: SceneContext) => unknown; visibleAt: (ms: number) => Readonly<Record<string, boolean>>; signature: string }`: A checked piece, the one contract renderers and tools read.
- **`formatStageError`** `(error: StageError): string`: One line saying what is wrong and where.
- **`StageError`** `type StageError = { readonly kind: "invalid"; readonly field: string; readonly reason: string; } | { readonly kind: "reserved_dot"; readonly name: string; } | { readonly kind: "unknown_beat"; readonly member: string; readonly beat: string; } | { readonly kind: "reversed_stretch"; readonly member: string; readonly from: string; readonly to: string; } | { readonly kind: "morph_mismatch"; readonly member: string; readonly reason: string; } | { readonly kind: "shape_mismatch"; readonly member: string; readonly reason: string; } | { readonly kind: "unknown_target"; readonly name: string; } | { readonly kind: "stroke_loop"; readonly loop: readonly string[]; readonly behind: readonly string[]; }`: Everything `compileStage`, `check` and stroke resolution can refuse.
- **`check`** `(stage: Stage, targets: Readonly<Record<string, unknown>>, counts?: Readonly<Record<string, number>>): readonly StageError[]`: Every shape mistake in a frame's targets: arrays or non-poses, lists not given as functions, unknown names.
- **`frame`** `(stage: Stage, input: FrameInput): FrameOutput`: Runs the scene once; single owner of `visible` across clock stretches and scroll windows.
- **`frameVisible`** `(targets: unknown): Readonly<Record<string, boolean>> | undefined`: Reads the per-member visibility map attached to a frame's `targets`, or undefined when absent.
- **`listPose`** `(value: unknown, index: number, count: number): Pose2d | undefined`: Item `index` of `count` from a list's target, or undefined when the scene gave none.
- **`listPose3d`** `(value: unknown, index: number, count: number): Pose3d | undefined`: Item `index` of `count` from a 3D list's target, or undefined when the scene gave none.
- **`partCounts`** `(stage: Stage, rest: RestReader, lines?: Readonly<Record<string, readonly number[]>>): Readonly<Record<string, number>>`: Each list member's part count from `<name>.<index>` boxes in `rest`, or `lines` when unboxed.
- **`pose3dOf`** `(value: unknown): Pose3d | undefined`: The 3D pose an object's target holds, or undefined when it holds none.
- **`poseOf`** `(value: unknown): Pose2d | undefined`: The pose a target holds, or undefined when it holds none.
- **`FrameInput`** `type FrameInput = { time: Time; events?: Events | undefined; rest?: RestReader | undefined; measures?: readonly RestAt[] | undefined; counts?: Readonly<Record<string, number>> | undefined; lines?: Readonly<Record<string, readonly number[]>> | undefined; only?: ReadonlySet<string> | undefined; moves?: Map<string, Moves> | undefined; drives?: Map<string, Drive> | undefined }`: One frame's inputs: the time, events, measured rest boxes, and re-measure history.
- **`FrameOutput`** `type FrameOutput = { visible: Readonly<Record<string, boolean>>; targets: Readonly<Record<string, unknown>> }`: One frame: who shows, and the scene's output as returned.
- **`beatAt`** `(beats: Readonly<Record<string, Span>>, durationMs: number, ms: number): string | undefined`: The latest-started beat whose window holds `ms`, or `undefined` in a gap between beats.
- **`Window`** `type Window = readonly [from: number, to: number]`: Ms a member shows, start included and end excluded; an end at the piece's last ms holds past it.
- **`blendShapes`** `(matched: readonly (readonly Cubic2d[])[], shape: number): readonly Cubic2d[]`: Interpolates matched outlines at `shape` index (clamped to `[0, matched.length - 1]`).
- **`matchOutlines`** `(outlines: readonly (readonly Cubic2d[])[]): { readonly matched: readonly (readonly Cubic2d[])[]; } | { readonly reason: string; }`: Matches outlines to blend smoothly by piece count, orientation, and cubic count.
- **`withFrameVisible`** `(targets: Readonly<Record<string, unknown>>, visible: Readonly<Record<string, boolean>>): Readonly<Record<string, unknown>>`: Attaches `visible` metadata to `targets` under a non-enumerable symbol.
