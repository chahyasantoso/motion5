# @gerak/stage: index

- **`actor`** `(options?: Behaviour & { readonly text?: ActorText; readonly path?: ActorPath; readonly shapes?: readonly (readonly Cubic2d[])[]; }): Actor`: One thing on stage, saying `text` or drawing the stroke `path` when given one.
- **`castNames`** `(cast: { readonly [x: string]: Member; }, beats?: readonly string[] | undefined): readonly CastName[]`: Every name the cast makes, in order, with presence taken from the nearest group that states it.
- **`presentAt`** `(on: readonly (readonly [string, string])[], spanOf: (beat: string) => { readonly from: number; readonly to: number; } | undefined, durationMs: number, ms: number): boolean`: Whether a member on these stretches shows at `ms`; a stretch reaching the story's end holds past it.
- **`group`** `(members: { readonly [x: string]: Member; }, options?: Behaviour): Group`: Members moved together; their keys join the cast's, so each must be unique across it.
- **`letters`** `(text: string, options?: Behaviour | undefined): Many`: A word or line split into its letters, one text actor each, in order; a letter is a grapheme, so an accented letter or an emoji is one.
- **`many`** `(count: number, options?: Behaviour | undefined): Many (+1 overloads)`: `count` things, or one per entry of `list` made by `make`; the scene answers one value per item.
- **`pathOf`** `(path: readonly Cubic2d[] | ((rest: Readonly<Record<string, Box>>) => readonly Cubic2d[]), rest: { readonly [x: string]: Box; }): readonly Cubic2d[]`: A path's cubics where things `rest`: a fixed list as it is, a function's answer checked and frozen; throws when the function throws or answers no cubics.
- **`words`** `(text: string, options?: Behaviour | undefined): Many`: A line split into its words at spaces, one text actor each, in order.
- **`Actor`** `type Actor = { kind: "actor"; text?: ActorText | undefined; path?: ActorPath | undefined; shapes?: readonly (readonly Cubic2d[])[] | undefined; on?: readonly Stretch[] | undefined; watch?: boolean | undefined; still?: boolean | undefined; ongoing?: boolean | undefined; pivot?: Pivot | undefined }`: One thing on stage; the scene answers one value for it, and a renderer's skin decides what it looks like.
- **`ActorPath`** `type ActorPath = readonly Cubic2d[] | ((rest: Readonly<Record<string, Box>>) => readonly Cubic2d[])`: A stroke as joined cubics in frame px from the frame's top-left, fixed or answered from where the other members rest; the stage places the member at the stroke's box.
- **`ActorText`** `type ActorText = string | ((time: Time) => string)`: What an actor says: fixed text, or a readout the renderer writes from the time on each frame.
- **`Behaviour`** `type Behaviour = { on?: readonly Stretch[] | undefined; watch?: boolean | undefined; still?: boolean | undefined; ongoing?: boolean | undefined; pivot?: Pivot | undefined }`: What a member does beside being moved: when it is shown, whether its pointer events reach the scene.
- **`Cast`** `type Cast<Record<string, Member>> = { readonly [x: string]: Member; }`: Who is on stage, by name; every key is unique across the whole cast, groups included.
- **`CastName`** `type CastName = { name: string; kind: "actor" | "many" | "group" | "item"; groups: readonly string[]; on?: readonly (readonly [string, string])[] | undefined; watch: boolean; still: boolean; ongoing: boolean; text?: ActorText | undefined; path?: ActorPath | undefined; shapes?: readonly (readonly Cubic2d[])[] | undefined; pivot?: Pivot | undefined }`: One name the cast makes: a member's key, or a key and an index for an item of `many`.
- **`Group`** `type Group = { kind: "group"; members: { readonly [x: string]: Member; }; on?: readonly Stretch[] | undefined; watch?: boolean | undefined; still?: boolean | undefined; ongoing?: boolean | undefined; pivot?: Pivot | undefined }`: Members moved together: the group's value applies to them, and each member's is relative to it.
- **`Many`** `type Many = { kind: "many"; items: readonly Actor[]; on?: readonly Stretch[] | undefined; watch?: boolean | undefined; still?: boolean | undefined; ongoing?: boolean | undefined; pivot?: Pivot | undefined }`: A list of things; the scene answers one value per item. To move the whole list, put it in a `group`.
- **`Member`** `type Member = Actor | Many | Group`: A cast member: what the scene's motion depends on, and nothing of how it looks.
- **`Pivot`** `type Pivot = { x: number; y: number }`: A point in frame px from the frame's top-left.
- **`Stretch`** `type Stretch = string | readonly [string, string]`: A stretch of the story: one beat, or a pair from the first beat's start to the second's end.
- **`blendShapes`** `(matched: readonly (readonly Cubic2d[])[], shape: number): readonly Cubic2d[]`: The cubics `shape` asks of matched outlines: 0 is the first, 1 the second, between them each control point is blended; clamped to the first and the last.
- **`matchOutlines`** `(outlines: readonly (readonly Cubic2d[])[]): { readonly matched: readonly (readonly Cubic2d[])[]; } | { readonly reason: string; }`: Outlines made to blend, the first being the path: the same pieces in the same order, each with as many cubics in every outline; or why they cannot.
- **`piecesOf`** `(cubics: readonly Cubic2d[]): readonly (readonly Cubic2d[])[]`: An outline split into its pieces: a cubic that does not start where the last ended starts another.
- **`DEFAULT_FRAME`** `const DEFAULT_FRAME: Frame`: The frame a module gets when it names none.
- **`frame`** `(size: Frame): Frame`: A stage `width` by `height` px.
- **`story`** `<const B extends string>(durationMs: number, beats: { readonly [P in keyof Record<B, readonly [number, number]>]: Record<B, readonly [number, number]>[P]; }): Readonly<Record<B, Span>> & { readonly durationMs: number; readonly order: readonly B[]; }`: Beats by name, each `[fromMs, toMs]` inside a piece `durationMs` long; beats may overlap.
- **`Frame`** `type Frame = { width: number; height: number }`: The stage's size in px; a renderer fits it to its container.
- **`Story`** `type Story<B> = Readonly<Record<B, Span>> & { readonly durationMs: number; readonly order: readonly B[]; }`: A piece's beats as named spans, its length, and the beats' names in the order they were given.
- **`cssVariables`** `(tokens: { readonly [x: string]: string; }): string`: A `:host` rule setting each token as a custom property, in the tokens' order; empty for none.
- **`isTokenName`** `(name: string): boolean`: Whether `name` is a custom property name a token may have: `--` then letters, digits, `-` or `_`.
- **`carried`** `(options: CarriedOptions): { readonly x?: number; readonly scale?: number; readonly y?: number; readonly rotation?: number; readonly skewX?: number; readonly skewY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly opacity?: number; readonly blur?: number; readonly shadowX?: number; readonly shadowY?: number; readonly shadowBlur?: number; readonly hue?: number; readonly lightness?: number; readonly tint?: number; readonly drawn?: number; readonly drawnFrom?: number; readonly clipX?: number; readonly clipY?: number; readonly clipRadius?: number; readonly clipWidth?: number; readonly clipHeight?: number; readonly shape?: number; readonly layer?: number; } & { readonly anchor?: Anchor; readonly custom?: Readonly<Record<string, number>>; }`: The pose of a member carried to the box `at` names after each event, over `ms` each, setting off from where it is drawn; with no clock it has arrived.
- **`carry`** `(own: Box, given: Box, target: Box, progress: number, size?: "scale" | "clip" | "keep"): { readonly x?: number; readonly scale?: number; readonly y?: number; readonly rotation?: number; readonly skewX?: number; readonly skewY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly opacity?: number; readonly blur?: number; readonly shadowX?: number; readonly shadowY?: number; readonly shadowBlur?: number; readonly hue?: number; readonly lightness?: number; readonly tint?: number; readonly drawn?: number; readonly drawnFrom?: number; readonly clipX?: number; readonly clipY?: number; readonly clipRadius?: number; readonly clipWidth?: number; readonly clipHeight?: number; readonly shape?: number; readonly layer?: number; } & { readonly anchor?: Anchor; readonly custom?: Readonly<Record<string, number>>; }`: The pose drawing a member resting at `own` on `from` at 0 and `to` at 1; `"clip"` only crops, never past `own`. Nothing is carried from or to a box with no size.
- **`CarriedOptions`** `type CarriedOptions = { own: Box; at: (events: Events) => Box; events: readonly MotionEvent[]; time: Time; ms: number; ease?: Ease | undefined; size?: CarrySize | undefined }`: What `carried` is given: where the member rests now, and where `at` says it belongs after the events.
- **`CarrySize`** `type CarrySize = "scale" | "clip" | "keep"`: How a carried member takes a box's size: `"scale"` stretches it, `"keep"` leaves it, `"clip"` leaves it and hides all outside the box.
- **`NO_LAYOUTS`** `const NO_LAYOUTS: {}`: The layouts a module with none passes: no layout, no boxes.
- **`NO_REST`** `const NO_REST: { readonly [x: string]: Box; }`: The rest a tool with no renderer passes: no boxes.
- **`restOf`** `(rest: { readonly [x: string]: Box; }, name: string): Box`: The box `name` rests in, or a zero box when nothing measured it, so a scene never throws on a tool's run.
- **`Box`** `type Box = { x: number; y: number; width: number; height: number }`: Where a member rests once laid out: its centre and size in px, in the frame's own space.
- **`Layouts`** `type Layouts<Record<L, Readonly<Record<string, Box>>>> = { readonly [P in keyof Record<L, Readonly<Record<string, Box>>>]: Record<L, Readonly<Record<string, Box>>>[P]; }`: Each named layout's `Rest`, as a renderer measured every one.
- **`Rest`** `type Rest<Record<string, Box>> = { readonly [x: string]: Box; }`: Each member's rest box by its cast name, as a renderer measured it after layout.
- **`readStageModule`** `(value: unknown): StageModule<string, object, string> | { readonly reason: string; }`: A stage module read from what a file exports, or why it is not one; it never throws.
- **`Skins`** `type Skins = { dom?: { readonly css?: string; readonly defs?: string; } | undefined }`: How the cast looks on each renderer; a member a skin leaves out gets the renderer's default.
- **`StageModule`** `type StageModule<B, V, L> = { beats: Readonly<Record<B, Span>> & { readonly durationMs: number; readonly order: readonly B[]; }; cast: { readonly [x: string]: Member; }; skins: Skins; scene: (time: Time, events: Events, rest: Readonly<Record<string, Box>>, layouts: Readonly<Record<L, Readonly<Record<string, Box>>>>) => V; frame?: Frame | undefined; rest?: Readonly<Record<string, Box>> | undefined; layouts?: readonly L[] | undefined; layout?: ((events: Events) => L) | undefined; rests?: Readonly<Record<L, Readonly<Record<string, Box>>>> | undefined; cues?: Events | undefined; design?: unknown; style?: string | undefined }`: What a stage module exports: its story, its cast, their skins and a scene answering `V`.
- **`describeLoop`** `({ loop, behind }: StrokeLoop): string`: The loop said in one line: `paths "a" and "b" read each other`, and any stroke reading them.
- **`drawInPasses`** `(paths: readonly (readonly [string, ActorPath])[], rest: { readonly [x: string]: Box; }, settle: (name: string, answer: PathAnswer, read: ReadonlySet<string>) => Box | undefined): StrokeLoop | undefined`: Draws strokes in passes over `rest` and the strokes drawn so far; a path reading an undrawn stroke waits, and `settle` answers a drawn one's box. Answers the loop when a pass draws none.
- **`restOfBounds`** `(bounds: Box): Box`: Where a stroke of these bounds rests: their centre and size, as a rest box is.
- **`thickened`** `(box: Box): Box`: A box never thinner than 1 on a side, so a straight line still shows: a side with no size opens to 1 about where it was.
- **`PathAnswer`** `type PathAnswer = { readonly kind: "drawn"; readonly cubics: readonly Cubic2d[]; } | { readonly kind: "failed"; readonly error: unknown; }`: What a path answered in its pass: its cubics, or what it threw.
- **`StrokeLoop`** `type StrokeLoop = { loop: readonly string[]; behind: readonly string[] }`: The strokes no pass could draw: those reading each other in a loop, and those reading one of them.
