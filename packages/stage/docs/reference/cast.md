# @gerak/stage: cast

Cast builders (`m.box`, `m.text`, `m.readout`, `m.stroke`, `m.morph`, `m.many`, `m.letters`, `m.words`, `m.group`), outline morphing, and dependency-ordered stroke resolution.

- **`blendShapes`** `(matched: readonly (readonly Cubic2d[])[], shape: number): readonly Cubic2d[]`: Interpolates matched outlines at `shape` index (clamped to `[0, matched.length - 1]`).
- **`compileCast`** `(castInput: unknown, beats: CompiledBeats): { readonly ok: true; readonly members: CompiledMembers; readonly reviewMembers: readonly ReviewMemberSpec[]; } | { readonly ok: false; readonly errors: readonly CastCompileError[]; }`: Validates and compiles a cast definition against compiled beats into runtime + review specs.
- **`createCastBuilder`** `<B extends string>(): CastBuilder<B>`: Creates the `CastBuilder` passed into `defineStage`'s `cast(m)` callback.
- **`describeLoop`** `({ loop, behind }: StrokeLoop): string`: Formats a `StrokeLoop` as a concise single-line dependency cycle description.
- **`drawInPasses`** `(paths: readonly (readonly [string, ActorPath])[], rest: RestReader, settle: (name: string, answer: PathAnswer, read: ReadonlySet<string>) => Box | undefined): StrokeLoop | undefined`: Resolves stroke paths in dependency order; returns `StrokeLoop` if any form a cycle.
- **`isCubics`** `(value: unknown): value is readonly Cubic2d[]`: Whether `value` is a non-empty list of valid `Cubic2d` segments.
- **`matchOutlines`** `(outlines: readonly (readonly Cubic2d[])[]): { readonly matched: readonly (readonly Cubic2d[])[]; } | { readonly reason: string; }`: Matches outlines to blend smoothly by piece count, orientation, and cubic count.
- **`pathOf`** `(path: ActorPath, rest: RestReader): readonly Cubic2d[]`: Resolves fixed or layout-dependent `ActorPath` cubics against `rest`, validating and freezing.
- **`piecesOf`** `(cubics: readonly Cubic2d[]): readonly (readonly Cubic2d[])[]`: Splits cubics into continuous outlines wherever a cubic does not start where the last ended.
- **`resolveStaticStrokes`** `(stage: { readonly members: CompiledMembers; }, rest?: RestReader): StrokeResolution`: Resolves all stroke and morph base outlines against `rest`, returning cubics or `stroke_loop`.
- **`restOfBounds`** `(bounds: Box): Box`: Converts top-left bounds `{ x, y, width, height }` into a center-origin `Box`.
- **`sameCast`** `(a: CompiledMembers, b: CompiledMembers): boolean`: Whether two compiled casts keep the same DOM/renderer tree structure, names, groups, and text.
- **`strokeBox`** `(cubics: readonly Cubic2d[]): Box`: Computes the thickened SVG viewBox bounds of a cubic outline.
- **`thickened`** `(box: Box): Box`: Grows bounds below 1 px to 1 px centered on the edge so straight lines stay visible.
- **`ActorContent`** `type ActorContent = { readonly kind: "empty"; } | { readonly kind: "text"; readonly value: string; } | { readonly kind: "readout"; readonly format: (time: Time) => string; } | { readonly kind: "stroke"; readonly path: ActorPath; } | { readonly kind: "morph"; readonly base: readonly Cubic2d[]; readonly targets: readonly (readonly Cubic2d[])[]; }`: Closed union describing what an actor displays on stage.
- **`ActorPath`** `type ActorPath = readonly Cubic2d[] | ((rest: RestReader) => readonly Cubic2d[])`: Fixed cubic segments or a layout-dependent function reading `RestReader`.
- **`CastBuilder`** `type CastBuilder<B> = { box: () => ListActorBuilder<B>; text: (value: string) => ListActorBuilder<B>; readout: (format: (time: Time) => string) => ReadoutActorBuilder<B>; stroke: (path: ActorPath) => ListActorBuilder<B>; morph: (base: readonly Cubic2d[], targets: readonly (readonly Cubic2d[])[]) => ListActorBuilder<B>; many: { (count: number): ListMemberBuilder<B>; <T>(items: readonly T[], make: (item: T, index: number) => ListActor<B>): ListMemberBuilder<B>; }; letters: (text: string) => ListMemberBuilder<B>; words: (text: string) => ListMemberBuilder<B>; group: <C extends Readonly<Record<string, Member<B>>>>(members: C) => GroupMemberBuilder<B, "settle", C> }`: Builder factory passed to `cast: (m) => ({ ... })` inside `defineStage`.
- **`CastCompileError`** `type CastCompileError = { readonly kind: "duplicate_member"; readonly name: string; } | { readonly kind: "reserved_dot_in_name"; readonly name: string; } | { readonly kind: "empty_on_stretches"; readonly member: string; } | { readonly kind: "unknown_beat"; readonly member: string; readonly beat: string; } | { readonly kind: "reversed_stretch"; readonly member: string; readonly from: string; readonly to: string; } | { readonly kind: "morph_mismatch"; readonly member: string; readonly reason: string; } | { readonly kind: "invalid_definition"; readonly field: "cast"; readonly reason: string; }`: Structured cast compilation failures produced before `compileStage` maps them to `StageError`.
- **`CompiledContent`** `type CompiledContent = { readonly kind: "empty"; } | { readonly kind: "text"; readonly value: string; } | { readonly kind: "readout"; readonly format: (time: Time) => string; } | { readonly kind: "stroke"; readonly path: ActorPath; } | { readonly kind: "morph"; readonly base: readonly Cubic2d[]; readonly targets: readonly (readonly Cubic2d[])[]; readonly matched: readonly (readonly Cubic2d[])[]; }`: Runtime actor content after compile-time morph matching.
- **`CompiledListItem`** `type CompiledListItem = { kind: "item"; name: string; list: string; index: number; content: { readonly kind: "empty"; } | { readonly kind: "text"; readonly value: string; } | { readonly kind: "stroke"; readonly path: ActorPath; } | { readonly kind: "morph"; readonly base: readonly Cubic2d[]; readonly targets: readonly (readonly Cubic2d[])[]; readonly matched: readonly (readonly Cubic2d[])[]; }; watch: boolean; on?: readonly CompiledStretch[] | undefined; pivot?: Pivot | undefined }`: Compiled item inside a `list` member.
- **`CompiledMember`** `type CompiledMember = { readonly kind: "actor"; readonly name: string; readonly content: CompiledContent; readonly watch: boolean; readonly on?: readonly CompiledStretch[] | undefined; readonly pivot?: Pivot | undefined; } | { readonly kind: "list"; readonly name: string; readonly items: readonly CompiledListItem[]; readonly watch: boolean; readonly on?: readonly CompiledStretch[] | undefined; readonly pivot?: Pivot | undefined; } | { readonly kind: "group"; readonly name: string; readonly members: Readonly<Record<string, CompiledMember>>; readonly watch: boolean; readonly on?: readonly CompiledStretch[] | undefined; readonly pivot?: Pivot | undefined; }`: Compiled member node in the runtime cast tree.
- **`CompiledMembers`** `type CompiledMembers = { tree: Readonly<Record<string, CompiledMember>>; entries: readonly MemberEntry[]; byName: ReadonlyMap<string, MemberEntry>; topLevel: readonly MemberEntry[]; morphs: readonly (MemberEntry & { readonly content: Extract<CompiledContent, { readonly kind: "morph"; }>; })[]; readouts: readonly (MemberEntry & { readonly content: Extract<CompiledContent, { readonly kind: "readout"; }>; })[] }`: Pure runtime cast representation held on `CompiledStage.members`, free of review metadata.
- **`GroupMemberBuilder`** `type GroupMemberBuilder<B, E, C> = { kind: "group"; members: C; meta: MemberMeta<B, E>; static: () => GroupMemberBuilder<B, "static", C>; ambient: () => GroupMemberBuilder<B, "ambient", C>; settle: () => GroupMemberBuilder<B, "settle", C>; on: (...stretches: Stretch<B>[]) => GroupMemberBuilder<B, E, C>; watch: (enabled?: boolean) => GroupMemberBuilder<B, E, C>; pivot: { (point: Pivot): GroupMemberBuilder<B, E, C>; (x: number, y: number): GroupMemberBuilder<B, E, C>; } }`: Fluent builder for `group` container members holding nested child members.
- **`ListActor`** `type ListActor<B, E> = { kind: "actor"; content: ListActorContent; meta: MemberMeta<B, E> }`: An item-compatible actor (`"readout"` excluded at compile time).
- **`ListActorBuilder`** `type ListActorBuilder<B, E> = { static: () => ListActorBuilder<B, "static">; ambient: () => ListActorBuilder<B, "ambient">; settle: () => ListActorBuilder<B, "settle">; kind: "actor"; content: ListActorContent; meta: MemberMeta<B, E>; on: (...stretches: Stretch<B>[]) => ListActorBuilder<B, E>; watch: (enabled?: boolean) => ListActorBuilder<B, E>; pivot: { (point: Pivot): ListActorBuilder<B, E>; (x: number, y: number): ListActorBuilder<B, E>; } }`: Fluent builder for item-compatible actors (`box`, `text`, `stroke`, `morph`).
- **`ListActorContent`** `type ListActorContent = { readonly kind: "empty"; } | { readonly kind: "text"; readonly value: string; } | { readonly kind: "stroke"; readonly path: ActorPath; } | { readonly kind: "morph"; readonly base: readonly Cubic2d[]; readonly targets: readonly (readonly Cubic2d[])[]; }`: Actor content permitted inside `list` members (disallows dynamic time `readout`).
- **`ListMemberBuilder`** `type ListMemberBuilder<B, E> = { kind: "list"; items: readonly ListActor<B, MotionExpectation>[]; meta: MemberMeta<B, E>; static: () => ListMemberBuilder<B, "static">; ambient: () => ListMemberBuilder<B, "ambient">; settle: () => ListMemberBuilder<B, "settle">; on: (...stretches: Stretch<B>[]) => ListMemberBuilder<B, E>; watch: (enabled?: boolean) => ListMemberBuilder<B, E>; pivot: { (point: Pivot): ListMemberBuilder<B, E>; (x: number, y: number): ListMemberBuilder<B, E>; } }`: Fluent builder for `many`, `letters`, and `words` list members.
- **`Member`** `type Member<B, E> = { readonly kind: "actor"; readonly content: ActorContent; readonly meta: MemberMeta<B, E>; } | { readonly kind: "list"; readonly items: readonly ListActor<B>[]; readonly meta: MemberMeta<B, E>; } | { readonly kind: "group"; readonly members: Readonly<Record<string, Member<B>>>; readonly meta: MemberMeta<B, E>; }`: Closed discriminated union of cast members: `"actor"`, `"list"`, or `"group"`.
- **`MemberEntry`** `type MemberEntry = { name: string; kind: "item" | "actor" | "list" | "group"; groups: readonly string[]; list?: string | undefined; index?: number | undefined; on?: readonly CompiledStretch[] | undefined; watch: boolean; pivot?: Pivot | undefined; content?: CompiledContent | undefined; itemCount?: number | undefined }`: Flat entry describing any member, list, group, or item for fast frame evaluation.
- **`MemberMeta`** `type MemberMeta<B, E> = { on?: readonly Stretch<B>[] | undefined; watch?: boolean | undefined; expectation?: E | undefined; pivot?: Pivot | undefined }`: Authored modifier metadata attached to a member or list item.
- **`MemberModifiers`** `type MemberModifiers<B, Self> = { on: (...stretches: Stretch<B>[]) => Self; watch: (enabled?: boolean) => Self; pivot: { (point: Pivot): Self; (x: number, y: number): Self; } }`: Fluent modifier API shared by actor, list, and group builders.
- **`PathAnswer`** `type PathAnswer = { readonly kind: "drawn"; readonly cubics: readonly Cubic2d[]; } | { readonly kind: "failed"; readonly error: unknown; }`: Outcome of evaluating one stroke path function in a dependency pass.
- **`Pivot`** `type Pivot = { x: number; y: number }`: Point in frame px around which a member rotates and scales.
- **`ReadoutActorBuilder`** `type ReadoutActorBuilder<B, E> = { kind: "actor"; content: { readonly kind: "readout"; readonly format: (time: Time) => string; }; meta: MemberMeta<B, E>; static: () => ReadoutActorBuilder<B, "static">; ambient: () => ReadoutActorBuilder<B, "ambient">; settle: () => ReadoutActorBuilder<B, "settle">; on: (...stretches: Stretch<B>[]) => ReadoutActorBuilder<B, E>; watch: (enabled?: boolean) => ReadoutActorBuilder<B, E>; pivot: { (point: Pivot): ReadoutActorBuilder<B, E>; (x: number, y: number): ReadoutActorBuilder<B, E>; } }`: Fluent builder for top-level `readout` actors (excluded from lists).
- **`ResolvedStroke`** `type ResolvedStroke = { name: string; cubics: readonly Cubic2d[]; box: Box }`: Resolved geometry and bounding rest box for one stroke or morph member.
- **`StrokeLoop`** `type StrokeLoop = { loop: readonly string[]; behind: readonly string[] }`: Cycle details when stroke path functions depend on one another without resolving.
- **`StrokeResolution`** `type StrokeResolution = { readonly ok: true; readonly strokes: ReadonlyMap<string, ResolvedStroke>; readonly rest: RestReader; readonly failures: readonly { readonly name: string; readonly error: unknown; }[]; readonly selfReads: readonly string[]; } | { readonly ok: false; readonly error: { readonly kind: "stroke_loop"; readonly loop: readonly string[]; readonly behind: readonly string[]; }; }`: Result of resolving all stroke and morph outlines against a `RestReader`.
