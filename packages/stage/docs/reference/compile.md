# @gerak/stage: compile

Stage compilation (`compileStage`), flattened typed scene target inference, and closed `StageError` formatting.

- **`compileStage`** `<P extends PoseMode = "2d", B extends string = string, C extends Readonly<Record<string, Member<B>>> = Readonly<Record<string, Member<B>>>, L extends string = never>(definition: StageDefinition<P, B, C, L>): CompileResult<CompiledStage<P>> (+1 overloads)`: Validates and compiles a `StageDefinition` (or unknown input) into a `CompiledStage`.
- **`formatStageError`** `(error: StageError): string`: Formats any `StageError` into a concise human-readable diagnostic via exhaustive switch.
- **`isCompiledStage`** `(value: unknown): value is CompiledStage<PoseMode>`: Whether `value` is a compiled stage returned by `compileStage`.
- **`isStage2d`** `(stage: CompiledStage<PoseMode>): stage is CompiledStage<"2d">`: Narrows a `CompiledStage` to `"2d"` pose stages when `stage.pose === "2d"`.
- **`isStageDefinition`** `(value: unknown): value is StageDefinition<PoseMode>`: Whether `value` was created by `defineStage`.
- **`CastKeys`** `type CastKeys<C> = string extends keyof C ? string : (keyof C & string) | { [K in keyof C]: ChildKeys<C[K]>; }[keyof C]`: Recursive union of cast member keys extracted from a cast tree `C`.
- **`CompileResult`** `type CompileResult<S> = { readonly ok: true; readonly stage: S; } | { readonly ok: false; readonly errors: readonly StageError[]; }`: Discriminated compilation outcome holding either a validated value or typed errors.
- **`CompiledStage`** `type CompiledStage<P> = { pose: P; beats: CompiledBeats<string>; frame: Frame; members: CompiledMembers; layout: LayoutSpec<string>; skins: Readonly<Omit<RendererSkins<string>, "dom"> & { readonly dom?: DomSkinCss | undefined; }>; cues: Events; review: CompiledReviewSpec }`: Validated runtime stage contract consumed by renderers and headless tools.
- **`FlattenedTargets`** `type FlattenedTargets<C, P> = keyof C extends never ? Readonly<Record<string, never>> : NestedTargets<C, P>`: Flattened scene return object type enforcing static/list/actor shape per cast member.
- **`PoseFor`** `type PoseFor<P> = P extends "2d" ? Pose2d : Pose3d`: Pose type selected by `PoseMode`: `Pose2d` for `"2d"`, `Pose3d` for `"3d"`.
- **`PoseMode`** `type PoseMode = "2d" | "3d"`: Supported pose coordinate modes for a stage definition.
- **`SceneContext`** `type SceneContext<P, B, L> = { time: Time; beats: CompiledBeats<B>; events: Events; rest: RestReader; layouts: Readonly<Record<L, RestReader>>; carry: CarryFn }`: Frame context passed to a stage `scene` callback.
- **`StageDefinition`** `type StageDefinition<P, B, C, L> = { kind: "stage-definition"; pose?: P | undefined; durationMs?: number | undefined; frame?: Frame | undefined; beats: Readonly<Record<B, BeatSpan>>; cast: (m: CastBuilder<NoInfer<B>>) => C; rest?: Readonly<Record<string, Box>> | undefined; layouts?: LayoutsInput<L> | undefined; skins?: StageSkinsInput<CastKeys<NoInfer<C>> extends never ? string : CastKeys<NoInfer<C>>> | undefined; cues?: Events | undefined; style?: string | undefined; design?: unknown; limits?: Readonly<Record<string, TargetLimits>> | undefined; scene: (ctx: SceneContext<NoInfer<P>, NoInfer<B>, NoInfer<L>>) => FlattenedTargets<NoInfer<C>, NoInfer<P>> }`: Frozen authored stage definition returned by `defineStage` before compilation.
- **`StageError`** `type StageError = { readonly kind: "duplicate_member"; readonly name: string; } | { readonly kind: "reserved_dot_in_name"; readonly name: string; } | { readonly kind: "empty_on_stretches"; readonly member: string; } | { readonly kind: "unknown_beat"; readonly member: string; readonly beat: string; } | { readonly kind: "reversed_stretch"; readonly member: string; readonly from: string; readonly to: string; } | { readonly kind: "morph_mismatch"; readonly member: string; readonly reason: string; } | { readonly kind: "stroke_loop"; readonly loop: readonly string[]; readonly behind: readonly string[]; } | { readonly kind: "invalid_initial_layout"; readonly message: string; } | { readonly kind: "empty_layouts"; } | { readonly kind: "shape_mismatch"; readonly member: string; readonly reason: string; } | { readonly kind: "invalid_definition"; readonly field: string; readonly reason: string; }`: Closed union of all compile-time and runtime stage validation errors.
- **`StageOptions`** `type StageOptions<P, B, C, L> = { pose?: P | undefined; durationMs?: number | undefined; frame?: Frame | undefined; beats: Readonly<Record<B, BeatSpan>>; cast: (m: CastBuilder<NoInfer<B>>) => C; rest?: Readonly<Record<string, Box>> | undefined; layouts?: LayoutsInput<L> | undefined; skins?: StageSkinsInput<CastKeys<NoInfer<C>> extends never ? string : CastKeys<NoInfer<C>>> | undefined; cues?: Events | undefined; style?: string | undefined; design?: unknown; limits?: Readonly<Record<string, TargetLimits>> | undefined; scene: (ctx: SceneContext<NoInfer<P>, NoInfer<B>, NoInfer<L>>) => FlattenedTargets<NoInfer<C>, NoInfer<P>> }`: Input options accepted by `defineStage`.
