# @gerak/stage: author

What a piece is written with: `defineStage`, the cast builders, list poses by index and the scene's context. Reach for it whenever you write a piece.

- **`ActorSpec`** `type ActorSpec<B, C> = { kind: "actor"; content: C; meta: Meta<B>; on: (...stretches: Stretch<B>[]) => ActorSpec<B, C>; watch: (enabled?: boolean) => ActorSpec<B, C>; pivot: (point: Pivot) => ActorSpec<B, C>; static: () => ActorSpec<B, C>; ambient: () => ActorSpec<B, C>; settle: () => ActorSpec<B, C> }`: One element on the stage.
- **`CastBuilder`** `type CastBuilder<B> = { box: () => ActorSpec<B, ItemContent>; text: (value: string) => ActorSpec<B, ItemContent>; readout: (format: (time: Time) => string) => ActorSpec<B, Extract<Content, { kind: "readout"; }>>; stroke: (path: Path) => ActorSpec<B, ItemContent>; morph: (base: readonly Cubic2d[], targets: readonly (readonly Cubic2d[])[]) => ActorSpec<B, ItemContent>; many: { (count: number): ListSpec<B>; <T>(items: readonly T[], make: (item: T, index: number) => ActorSpec<B, ItemContent>): ListSpec<B>; }; letters: (text: string) => ListSpec<B>; words: (text: string) => ListSpec<B>; group: <M extends Members<B>>(members: M) => GroupSpec<B, M> }`: The builders `cast: (m) => ({ ... })` receives.
- **`Content`** `type Content = { readonly kind: "box"; } | { readonly kind: "text"; readonly value: string; } | { readonly kind: "readout"; readonly format: (time: Time) => string; } | { readonly kind: "stroke"; readonly path: Path; } | { readonly kind: "morph"; readonly shapes: readonly (readonly Cubic2d[])[]; }`: What an actor shows; `morph` holds its base outline first, then each target outline.
- **`Expect`** `type Expect = "settle" | "ambient" | "static"`: What review expects of a member: it moves and settles, it keeps moving, or the scene never poses it.
- **`GroupSpec`** `type GroupSpec<B, M> = { kind: "group"; members: M; meta: Meta<B>; on: (...stretches: Stretch<B>[]) => GroupSpec<B, M>; watch: (enabled?: boolean) => GroupSpec<B, M>; pivot: (point: Pivot) => GroupSpec<B, M>; static: () => GroupSpec<B, M>; ambient: () => GroupSpec<B, M>; settle: () => GroupSpec<B, M> }`: A container whose pose moves its children; children are named flat beside it in the scene.
- **`ItemContent`** `type ItemContent = { readonly kind: "box"; } | { readonly kind: "text"; readonly value: string; } | { readonly kind: "stroke"; readonly path: Path; } | { readonly kind: "morph"; readonly shapes: readonly (readonly Cubic2d[])[]; }`: What a list item shows: any content but a readout.
- **`ListSpec`** `type ListSpec<B> = { kind: "list"; items: readonly ItemContent[]; meta: Meta<B>; on: (...stretches: Stretch<B>[]) => ListSpec<B>; watch: (enabled?: boolean) => ListSpec<B>; pivot: (point: Pivot) => ListSpec<B>; static: () => ListSpec<B>; ambient: () => ListSpec<B>; settle: () => ListSpec<B> }`: A row of items posed by index; the scene gives it `(index, count) => pose`.
- **`Members`** `type Members<B> = { readonly [x: string]: Spec<B>; }`: Members by name.
- **`Meta`** `type Meta<B> = { on?: readonly Stretch<B>[] | undefined; watch?: boolean | undefined; expect?: Expect | undefined; pivot?: Pivot | undefined }`: A member's modifiers as written.
- **`Modifiers`** `type Modifiers<B, S> = { on: (...stretches: Stretch<B>[]) => S; watch: (enabled?: boolean) => S; pivot: (point: Pivot) => S; static: () => S; ambient: () => S; settle: () => S }`: Modifiers every member takes; each returns a new member.
- **`Path`** `type Path = readonly Cubic2d[] | ((rest: RestReader) => readonly Cubic2d[])`: A stroke's outline: fixed cubics, or cubics drawn from the rest boxes of other members.
- **`Pivot`** `type Pivot = { x: number; y: number }`: The point in frame px a member turns and scales around.
- **`Spec`** `type Spec<B> = ActorSpec<B, Content> | ListSpec<B> | GroupSpec<B, Readonly<Record<string, Spec<B>>>>`: Any member as written.
- **`Stretch`** `type Stretch<B> = B | readonly [B, B]`: When a member shows: one beat, or every beat from the first to the second.
- **`beat`** `(name: string, ms: number, place?: BeatPlace): Beat`: A beat `ms` long; `{ at }` starts it at a ms, `{ after, gap }` starts it `gap` ms after another ends.
- **`Beat`** `type Beat = { name: string; from: number; to: number; of: (time: Time, ease?: Ease) => Time; at: (share: number) => number }`: A named stretch of the piece: a core `Span` that also says what it is called.
- **`BeatPlace`** `type BeatPlace = { readonly at?: number; } | { readonly after: Beat; readonly gap?: number; }`: Where a beat starts: at a ms (default 0), or after another beat with an optional gap.
- **`box`** `(name: string, options?: ElementOptions): Element`: A page element styled by CSS.
- **`group`** `(name: string, children: readonly Element[], options?: ElementOptions): Element`: A container: its pose moves its children, and each child keeps its own motions.
- **`many`** `(name: string, count: number, options?: ElementOptions): Element (+1 overloads)`: A row of numbered parts: `count` boxes, or one part per item, each made by `make`.
- **`shape`** `(name: string, outline: ShapeSource, options?: ElementOptions): Element`: A drawn path, or a morph between outlines: 0 is `base`, 1 is `targets[0]`.
- **`text`** `(name: string, content: string | ((time: Time) => string), options?: TextOptions): Element`: Text, or text a function of time writes; `split` gives a string a part per letter or word.
- **`Element`** `type Element = { readonly kind: "box"; readonly name: string; readonly options: ElementOptions; } | { readonly kind: "shape"; readonly name: string; readonly outline: Outline; readonly options: ElementOptions; } | { readonly kind: "text"; readonly name: string; readonly content: string | ((time: Time) => string); readonly split: "letters" | "words" | undefined; readonly options: ElementOptions; } | { readonly kind: "many"; readonly name: string; readonly items: readonly ItemContent[]; readonly options: ElementOptions; } | { readonly kind: "group"; readonly name: string; readonly children: readonly Element[]; readonly options: ElementOptions; }`: An element of a piece, made once with a name; `kind` says what it is.
- **`ElementOptions`** `type ElementOptions = { pivot?: Pivot | undefined; watch?: boolean | undefined }`: What stays true of an element in any scene: where it turns, and whether pointer events reach it.
- **`MorphSource`** `type MorphSource = { base: readonly Cubic2d[]; targets: readonly (readonly Cubic2d[])[] }`: A base outline with the outlines it blends to.
- **`Outline`** `type Outline = { readonly kind: "path"; readonly path: Path; } | { readonly kind: "morph"; readonly base: readonly Cubic2d[]; readonly targets: readonly (readonly Cubic2d[])[]; }`: What a shape draws: a path, or a base outline with the outlines it blends to.
- **`ShapeSource`** `type ShapeSource = Path | MorphSource`: What `shape` draws: a path, or a morph.
- **`TextOptions`** `type TextOptions = { split?: "letters" | "words" | undefined; pivot?: Pivot | undefined; watch?: boolean | undefined }`: Options of `text`: how to split it into parts.
- **`bind`** `(fields: BoundFields): Motion<Pose2d, MotionContext>`: A motion setting each field from its signal at the scene's time.
- **`bindEach`** `(fields: BoundEachFields): Motion<Pose2d, MotionContext>`: A motion setting each field of each part of a list element from that part's signal at the scene's time.
- **`carry`** `(options: CarryOptions): Motion<Pose2d, MotionContext>`: A motion giving the element's move from its box in the last layout to its box in the next. A part of a list uses its box named `<element>.<index>`.
- **`sceneBuilder`** `(options?: SceneBuilderOptions): SceneBuilder`: Starts a piece; the chain's value is a `StageDefinition`, so every tool, page and renderer reads it.
- **`stagger`** `(inner: Motion<Pose2d, MotionContext>, options: StaggerOptions): Motion<Pose2d, MotionContext>`: Plays `inner` on each part of a list element in its own lane; without parts it plays `inner` as it is. Lanes run inside the span of `inner` when it has one.
- **`stayWith`** `(element: Element): Motion<Pose2d, MotionContext>`: A motion giving the change in `element`'s pose since the start of its own span; it reads `element`.
- **`BoundEachFields`** `type BoundEachFields = { layer?: (index: number) => Signal<number>; x?: (index: number) => Signal<number>; scale?: (index: number) => Signal<number>; y?: (index: number) => Signal<number>; rotation?: (index: number) => Signal<number>; skewX?: (index: number) => Signal<number>; skewY?: (index: number) => Signal<number>; scaleX?: (index: number) => Signal<number>; scaleY?: (index: number) => Signal<number>; opacity?: (index: number) => Signal<number>; blur?: (index: number) => Signal<number>; shadowX?: (index: number) => Signal<number>; shadowY?: (index: number) => Signal<number>; shadowBlur?: (index: number) => Signal<number>; hue?: (index: number) => Signal<number>; lightness?: (index: number) => Signal<number>; tint?: (index: number) => Signal<number>; drawn?: (index: number) => Signal<number>; drawnFrom?: (index: number) => Signal<number>; clipX?: (index: number) => Signal<number>; clipY?: (index: number) => Signal<number>; clipRadius?: (index: number) => Signal<number>; clipWidth?: (index: number) => Signal<number>; clipHeight?: (index: number) => Signal<number>; shape?: (index: number) => Signal<number> }`: The fields `bindEach` sets: each maps a part's index to its signal.
- **`BoundFields`** `type BoundFields = { layer?: Signal<number>; x?: Signal<number>; scale?: Signal<number>; y?: Signal<number>; rotation?: Signal<number>; skewX?: Signal<number>; skewY?: Signal<number>; scaleX?: Signal<number>; scaleY?: Signal<number>; opacity?: Signal<number>; blur?: Signal<number>; shadowX?: Signal<number>; shadowY?: Signal<number>; shadowBlur?: Signal<number>; hue?: Signal<number>; lightness?: Signal<number>; tint?: Signal<number>; drawn?: Signal<number>; drawnFrom?: Signal<number>; clipX?: Signal<number>; clipY?: Signal<number>; clipRadius?: Signal<number>; clipWidth?: Signal<number>; clipHeight?: Signal<number>; shape?: Signal<number> }`: The fields `bind` sets: any numeric field of a pose.
- **`ElementStep`** `type ElementStep = { motion: (...motions: readonly SceneMotion[]) => ElementStep; modify: (principle: Principle) => ElementStep; show: (...windows: readonly ShowWindow[]) => ElementStep; limits: ((limits: Limits) => ElementStep) & Readonly<Record<string, Limits>>; element: (element: Element) => ElementStep; kind: "stage-definition"; beats: Readonly<Record<string, readonly [number, number]>>; durationMs?: number | undefined; frame?: Frame | undefined; cast: (m: CastBuilder<string>) => Readonly<Record<string, Spec<string>>>; rest?: Readonly<Record<string, Box>> | undefined; layouts?: LayoutsInput<string> | undefined; skins?: { readonly dom?: DomSkinInput | undefined; } | undefined; cues?: Events | undefined; scene: (context: SceneContext<string, string>) => Readonly<Record<string, Pose2d | ListPose | undefined>> }`: A piece with one element selected; the order of `.motion` and `.modify` calls matters.
- **`MotionContext`** `type MotionContext = { time: Time; events: Events; index?: number; count?: number; rest: RestReader; carry: Carry; element: string; span: Span | undefined; read: (element: Element | string, at?: ReadAt) => Pose2d }`: What a motion reads each frame, beside the time it plays in.
- **`Principle`** `type Principle = (signal: Signal<Pose2d>) => Signal<Pose2d>`: Wraps the signal of every motion above it in a `.modify` call.
- **`ReadAt`** `type ReadAt = { time?: Time; index?: number; count?: number }`: Where `read` looks: another time, or another part of a list.
- **`SceneBuilder`** `type SceneBuilder = { element: (element: Element) => ElementStep; kind: "stage-definition"; beats: Readonly<Record<string, readonly [number, number]>>; durationMs?: number | undefined; frame?: Frame | undefined; cast: (m: CastBuilder<string>) => Readonly<Record<string, Spec<string>>>; rest?: Readonly<Record<string, Box>> | undefined; layouts?: LayoutsInput<string> | undefined; skins?: { readonly dom?: DomSkinInput | undefined; } | undefined; cues?: Events | undefined; limits?: Readonly<Record<string, Limits>> | undefined; scene: (context: SceneContext<string, string>) => Readonly<Record<string, Pose2d | ListPose | undefined>> }`: A piece being written: itself a `StageDefinition`, and `.element` selects what to give motions.
- **`SceneBuilderOptions`** `type SceneBuilderOptions = { skins?: { readonly dom?: DomSkinInput | undefined; } | undefined; frame?: Frame | undefined; cues?: Events | undefined; length?: number | undefined; layouts?: LayoutsInput<string> | undefined }`: Options of `sceneBuilder`: what is true of the whole piece.
- **`SceneMotion`** `type SceneMotion = (time: Time, context: MotionContext) => Pose2d`: A core `Motion`, or a plain function from time and context to a pose.
- **`ShowWindow`** `type ShowWindow = Beat | readonly [from: Beat, to: Beat]`: A beat, or two beats: from the start of the first to the end of the second.
- **`StaggerFrom`** `type StaggerFrom = "start" | "end" | "center" | "edges"`: Which part of a staggered list starts first.
- **`StaggerOptions`** `type StaggerOptions = { spread: number; from?: StaggerFrom | undefined }`: Settings of `stagger`: `spread` is the gap between starts in lane lengths, as `lanes` reads it.
- **`NO_REST`** `const NO_REST: RestReader`: A reader with no boxes, as headless runs have.
- **`ZERO_BOX`** `const ZERO_BOX: Box`: Zero box answered for a name never measured.
- **`restReader`** `(rest?: Rest): RestReader`: A `RestReader` over `rest`.
- **`Box`** `type Box = { x: number; y: number; width: number; height: number }`: Where a member rests once laid out: its centre and size in frame px.
- **`Carry`** `type Carry = (member: string, options: CarryOptions) => Pose2d`: Moves `member` from its box in the last layout to its box in the next, over `options.ms`.
- **`CarryMode`** `type CarryMode = "scale" | "clip" | "keep"`: How a carried member takes the size of its target box.
- **`CarryOptions`** `type CarryOptions = { ms: number; ease?: Ease | undefined; mode?: CarryMode | undefined; target?: ((events: Events, layout: RestReader) => Box) | undefined }`: Options of `carry`: transition length, easing, sizing, and an optional target box.
- **`Frame`** `type Frame = { width: number; height: number }`: Stage size in px.
- **`Rest`** `type Rest = { readonly [x: string]: Box; }`: Rest boxes by member name.
- **`RestReader`** `type RestReader = { get: (name: string) => Box; has: (name: string) => boolean; keys: () => readonly string[] }`: Reads rest boxes; a name never measured answers a zero box.
- **`defineStage`** `<const B extends string, M extends Members<B>, const L extends string = never>(options: StageOptions<B, M, L>): StageDefinition<B, M, L>`: Declares a piece; its beat and layout names type the cast's `on` and the scene's context.
- **`each`** `<T>(items: readonly T[], pose: (item: T, index: number) => Pose2d): ListPose`: A list pose from per-item data: item `index` takes `pose(items[index], index)`, one past the data none.
- **`isStageDefinition`** `(value: unknown): value is StageDefinition`: Whether `value` reads as what `defineStage` returns: `kind` only, so a second copy of the package passes.
- **`Beats`** `type Beats<B> = { readonly [P in keyof Record<B, Span>]: Record<B, Span>[P]; }`: Beats by name, each a `Span`: `beats.enter.of(time)` is time inside it.
- **`DomSkinInput`** `type DomSkinInput = { readonly css: string; readonly defs?: string | undefined; } | { readonly css: URL; readonly defs?: URL | undefined; }`: The DOM skin: CSS and SVG defs as strings, or as URLs of files beside the piece.
- **`Limits`** `type Limits = { jump?: number | undefined; turn?: number | undefined; ratio?: number | undefined }`: Review limits of one target, overriding the command's defaults.
- **`LayoutsInput`** `type LayoutsInput<L> = { names: readonly [L, ...L[]]; pick?: ((events: Events) => L) | undefined; rests?: Readonly<Record<L, Readonly<Record<string, Box>>>> | undefined }`: Named layouts: `pick` answers which shows after the given events, and `rests` measures each headless.
- **`ListPose`** `type ListPose = (index: number, count: number) => Pose2d`: A list's pose in the scene: the pose of item `index` of `count`.
- **`MemberName`** `type MemberName<M> = { [K in keyof M & string]: K | (M[K] extends { readonly kind: "group"; readonly members: infer G; } ? MemberName<G> : never); }[keyof M & string]`: Every member name of a cast, group children included.
- **`MemberOf`** `type MemberOf<M, K> = K extends keyof M ? M[K] : { [G in keyof M]: M[G] extends { readonly kind: "group"; readonly members: infer H; } ? MemberOf<H, K> : never; }[keyof M]`: The member named `K` in a cast, looked up inside groups too.
- **`SceneContext`** `type SceneContext<B, L> = { time: Time; beats: Readonly<Record<B, Span>>; events: Events; rest: RestReader; layouts: Readonly<Record<L, RestReader>>; carry: Carry }`: What the scene reads each frame.
- **`StageDefinition`** `type StageDefinition<B, M, L> = { kind: "stage-definition"; beats: Readonly<Record<B, readonly [number, number]>>; durationMs?: number | undefined; frame?: Frame | undefined; cast: (m: CastBuilder<NoInfer<B>>) => M; rest?: Readonly<Record<string, Box>> | undefined; layouts?: LayoutsInput<L> | undefined; skins?: { readonly dom?: DomSkinInput | undefined; } | undefined; cues?: Events | undefined; limits?: Readonly<Record<string, Limits>> | undefined; scene: (context: SceneContext<NoInfer<B>, NoInfer<L>>) => Targets<NoInfer<M>> }`: A piece as `defineStage` returns it, before `compileStage` checks it.
- **`StageOptions`** `type StageOptions<B, M, L> = { beats: Readonly<Record<B, readonly [number, number]>>; durationMs?: number | undefined; frame?: Frame | undefined; cast: (m: CastBuilder<NoInfer<B>>) => M; rest?: Readonly<Record<string, Box>> | undefined; layouts?: LayoutsInput<L> | undefined; skins?: { readonly dom?: DomSkinInput | undefined; } | undefined; cues?: Events | undefined; limits?: Readonly<Record<string, Limits>> | undefined; scene: (context: SceneContext<NoInfer<B>, NoInfer<L>>) => Targets<NoInfer<M>> }`: A piece as written: beats in ms, a cast, and a scene from time to poses.
- **`Targets`** `type Targets<M> = string extends keyof M ? Readonly<Record<string, Pose2d | ListPose | undefined>> : { readonly [K in MemberName<M>]?: MemberOf<M, K> extends { readonly kind: "list"; } ? ListPose : Pose2d; }`: What the scene returns: a pose per actor or group, a `ListPose` per list, all named flat.
