# @gerak/stage: author

What a piece is written with: `sceneBuilder`, its elements, beats and motions. Reach for it whenever you write a piece.

- **`Content`** `type Content = { readonly kind: "box"; } | { readonly kind: "text"; } | { readonly kind: "readout"; readonly format: (time: Time) => string; } | { readonly kind: "stroke"; readonly path: Path; } | { readonly kind: "morph"; readonly shapes: readonly (readonly Cubic2d[])[]; }`: What an actor shows; `morph` holds its base outline first, then each target outline.
- **`Expect`** `type Expect = "settle" | "ambient" | "static"`: What review expects of a member: it moves and settles, it keeps moving, or the scene never poses it.
- **`Path`** `type Path = readonly Cubic2d[] | ((rest: RestReader) => readonly Cubic2d[])`: A stroke's outline: fixed cubics, or cubics drawn from the rest boxes of other members.
- **`beat`** `(name: string, ms: number, place?: BeatPlace): Beat (+2 overloads)`: A clock beat `ms` long, a triggered beat `{ when, back }`, or a scroll window `{ scroll: [from, to] }`.
- **`scrollPoint`** `(px: number): ScrollPoint`: A scroll position in `px`, with `.plus(px)`, `.minus(px)` and `.reached`.
- **`Beat`** `type Beat = { name: string; from: number; to: number; of: (time: Time, ease?: Ease) => Time; at: (share: number) => number }`: A named stretch of the piece in ms: a core `Span` that also says what it is called.
- **`BeatContext`** `type BeatContext = { events?: Events | undefined; rest?: RestReader | undefined }`: Context a scroll or trigger beat reads when mapping time: events so far and measured rests.
- **`BeatPlace`** `type BeatPlace = { readonly at?: number; } | { readonly after: Beat; readonly gap?: number; }`: Where a clock beat starts: at a ms (default 0), or after another beat with an optional gap.
- **`ScrollBeat`** `type ScrollBeat = { kind: "scroll-beat"; name: string; from: ScrollPoint; to: ScrollPoint; smooth: boolean; of: (time: Time, ease?: Ease, context?: BeatContext) => Time; active: (time: Time, context?: BeatContext) => boolean; moving: (time: Time, context?: BeatContext) => boolean }`: A named window over scroll position, mapping `from` to `to` into progress 0 to 1.
- **`ScrollBeatOptions`** `type ScrollBeatOptions = { scroll: readonly [from: ScrollPoint, to: ScrollPoint]; smooth?: true | SpringToOptions }`: Settings of a scroll beat: `[from, to]` scroll points mapping 0 to 1, and `smooth` to trail the scroll.
- **`ScrollPoint`** `type ScrollPoint = { kind: "scroll-point"; at: (rest?: RestReader) => number; plus: (px: number) => ScrollPoint; minus: (px: number) => ScrollPoint; reached: ScrollReached }`: A scroll position or an element's edge in px, resolved against measured page rest boxes.
- **`ScrollReached`** `type ScrollReached = { kind: "scroll-reached"; point: ScrollPoint }`: A trigger condition that fires when scroll passes `point`.
- **`TriggerBack`** `type TriggerBack = "reverse" | "stay" | "replay"`: What scrolling back past a trigger point does: reverse cleanly, stay at its end, or reset to replay.
- **`TriggerBeat`** `type TriggerBeat = { kind: "trigger-beat"; name: string; ms: number; when: ScrollReached; back: TriggerBack; of: (time: Time, ease?: Ease, context?: BeatContext) => Time; active: (time: Time, context?: BeatContext) => boolean; moving: (time: Time, context?: BeatContext) => boolean; heading: (time: Time, context?: BeatContext) => -1 | 0 | 1 }`: A named clock beat started when scroll passes `when.point`, with explicit `back` behaviour.
- **`TriggerPlace`** `type TriggerPlace = { when: ScrollReached; back: TriggerBack }`: Settings of a triggered clock beat: `when` scroll passes a point, and what scrolling `back` does.
- **`box`** `(name: string, options?: BoxOptions): Element`: A page element styled by CSS; `parts: true` binds it to a list of parts.
- **`object`** `(name: string, options?: ObjectOptions): ObjectElement`: A Three.js object; its origin is the `Object3D`'s, and it has no DOM node, content or pointer events.
- **`shape`** `(name: string, outline: ShapeSource, options?: ElementOptions): Element`: A drawn path, or a morph between outlines: 0 is `base`, 1 is `targets[0]`.
- **`text`** `(name: string, options?: TextOptions): Element (+1 overloads)`: Text in the markup, or text a function of time writes; `split` gives one part per letter or word.
- **`BoxOptions`** `type BoxOptions = { parts?: boolean | undefined; watch?: boolean | undefined }`: Options of `box`: whether it binds to a list of parts.
- **`Element`** `type Element = ElementBody & Edges`: An element of a piece, made once with a name; `kind` says what it is.
- **`Edges`** `type Edges = { top: ScrollPoint; end: ScrollPoint }`: An element's measured edges as scroll points: the top and the bottom of its rest box.
- **`ElementBody`** `type ElementBody = { readonly kind: "box"; readonly name: string; readonly parts?: boolean | undefined; readonly options: ElementOptions; } | { readonly kind: "shape"; readonly name: string; readonly outline: Outline; readonly options: ElementOptions; } | { readonly kind: "text"; readonly name: string; readonly content?: ((time: Time) => string) | undefined; readonly split: "letters" | "words" | undefined; readonly options: ElementOptions; }`: What an element is, before its edges.
- **`ElementOptions`** `type ElementOptions = { watch?: boolean | undefined }`: What stays true of an element in any scene: whether pointer events reach it.
- **`ObjectElement`** `type ObjectElement = { kind: "object"; name: string; view: ObjectView | undefined }`: A Three.js object of a piece, posed in `Pose3d` world units and drawn by `bindScene3d`, never by a DOM renderer.
- **`ObjectOptions`** `type ObjectOptions = { view?: ObjectView | undefined }`: Options of `object`: its view, which `travel` onto a page slot needs.
- **`ObjectView`** `type ObjectView = { canvas: Element; lens: Lens3d }`: Where an object is drawn: the element bound to the page's canvas, and the fixed lens the page draws through.
- **`SceneElement`** `type SceneElement = Element | ObjectElement`: Any element of a piece: one a DOM renderer draws, or a Three.js object.
- **`MorphSource`** `type MorphSource = { base: readonly Cubic2d[]; targets: readonly (readonly Cubic2d[])[] }`: A base outline with the outlines it blends to.
- **`Outline`** `type Outline = { readonly kind: "path"; readonly path: Path; } | { readonly kind: "morph"; readonly base: readonly Cubic2d[]; readonly targets: readonly (readonly Cubic2d[])[]; }`: What a shape draws: a path, or a base outline with the outlines it blends to.
- **`ShapeSource`** `type ShapeSource = Path | MorphSource`: What `shape` draws: a path, or a morph.
- **`TextOptions`** `type TextOptions = { split?: "letters" | "words" | undefined; watch?: boolean | undefined }`: Options of `text`: how to split it into parts.
- **`bind`** `(fields: BoundFields): Motion<Pose2d, MotionContext>`: A motion setting each field from its signal at the scene's time.
- **`bindEach`** `(fields: BoundEachFields): Motion<Pose2d, MotionContext>`: A motion setting each field of each part of a list element from that part's signal at the scene's time.
- **`carry`** `(options: CarryOptions): Motion<Pose2d, MotionContext>`: A motion giving the element's move from its old rest box to its new one after a re-measure. A part of a list uses its box named `<element>.<index>`.
- **`compileScene`** `(scene: SceneBuilder, options?: CompileSceneOptions): CompileResult`: The stage a scene plays as, or every reason it cannot.
- **`isScene`** `(value: unknown): value is SceneBuilder`: Whether `value` is a piece written with `sceneBuilder`.
- **`sceneBuilder`** `(options?: SceneBuilderOptions): SceneBuilder`: Starts a piece; `compileScene` turns the chain's value into the stage the renderers play.
- **`stagger`** `(inner: Motion<Pose2d, MotionContext>, options: StaggerOptions): Motion<Pose2d, MotionContext> (+1 overloads)`: Plays `inner` on each part of a list element in its own lane; without parts it plays as it is. A function builds each part's motion from `(index, count)`; its traits come from `(0, 1)`.
- **`stayWith`** `(element: Element): Motion<Pose2d, MotionContext>`: A motion giving the change in `element`'s pose since the start of its own clock span; it reads `element`.
- **`travel`** `(options: TravelOptions): TravelMotion`: Moves an element from its current pose into `options.to`'s measured box over its beat, evenly scaled unless `fit: "fill"`; with no window on a live or untimed clock it sits there.
- **`TravelMotion`** `type TravelMotion = { (time: Time, context?: MotionContext | undefined): Pose2d; travel: TravelOptions; in: (window: InWindow, ease?: Ease) => TravelMotion; loop: (ms: number) => TravelMotion; take: () => TravelMotion; ambient: () => TravelMotion; span: Span | undefined; window: InWindow | undefined; period: number | undefined; joins: Joins; isAmbient: boolean }`: What `travel` returns: a motion on an element, which an object with a view also takes.
- **`BoundEachFields`** `type BoundEachFields = { layer?: (index: number) => Signal<number>; x?: (index: number) => Signal<number>; scale?: (index: number) => Signal<number>; y?: (index: number) => Signal<number>; rotation?: (index: number) => Signal<number>; skewX?: (index: number) => Signal<number>; skewY?: (index: number) => Signal<number>; scaleX?: (index: number) => Signal<number>; scaleY?: (index: number) => Signal<number>; opacity?: (index: number) => Signal<number>; blur?: (index: number) => Signal<number>; shadowX?: (index: number) => Signal<number>; shadowY?: (index: number) => Signal<number>; shadowBlur?: (index: number) => Signal<number>; hue?: (index: number) => Signal<number>; lightness?: (index: number) => Signal<number>; tint?: (index: number) => Signal<number>; drawn?: (index: number) => Signal<number>; drawnFrom?: (index: number) => Signal<number>; clipX?: (index: number) => Signal<number>; clipY?: (index: number) => Signal<number>; clipRadius?: (index: number) => Signal<number>; clipWidth?: (index: number) => Signal<number>; clipHeight?: (index: number) => Signal<number>; shape?: (index: number) => Signal<number> }`: The fields `bindEach` sets: each maps a part's index to its signal.
- **`BoundFields`** `type BoundFields = { layer?: Signal<number>; x?: Signal<number>; scale?: Signal<number>; y?: Signal<number>; rotation?: Signal<number>; skewX?: Signal<number>; skewY?: Signal<number>; scaleX?: Signal<number>; scaleY?: Signal<number>; opacity?: Signal<number>; blur?: Signal<number>; shadowX?: Signal<number>; shadowY?: Signal<number>; shadowBlur?: Signal<number>; hue?: Signal<number>; lightness?: Signal<number>; tint?: Signal<number>; drawn?: Signal<number>; drawnFrom?: Signal<number>; clipX?: Signal<number>; clipY?: Signal<number>; clipRadius?: Signal<number>; clipWidth?: Signal<number>; clipHeight?: Signal<number>; shape?: Signal<number> }`: The fields `bind` sets: any numeric field of a pose.
- **`CompileSceneOptions`** `type CompileSceneOptions = { wrap?: ((run: Stage["scene"]) => Stage["scene"]) | undefined }`: How a scene compiles: a wrap around each frame's poses.
- **`ElementStep`** `type ElementStep = { motion: (...motions: readonly SceneMotion[]) => ElementStep; modify: (principle: Principle) => ElementStep; show: (...windows: readonly ShowWindow[]) => ElementStep; limits: (limits: Limits) => ElementStep; kind: "scene"; element: { (element: ObjectElement): ObjectStep; (element: Element): ElementStep; }; include: (scene: SceneBuilder) => SceneBuilder }`: A piece with one element selected; the order of `.motion` and `.modify` calls matters.
- **`ObjectStep`** `type ObjectStep = { motion: { (...motions: readonly SceneMotion3d[]): ObjectStep; (...motions: readonly (SceneMotion3d | TravelMotion)[]): ObjectStep; }; modify: (principle: Principle3d) => ObjectStep; show: (...windows: readonly ShowWindow[]) => ObjectStep; limits: (limits: Limits) => ObjectStep; kind: "scene"; element: { (element: ObjectElement): ObjectStep; (element: Element): ElementStep; }; include: (scene: SceneBuilder) => SceneBuilder }`: A piece with an object selected: its motions and principles are 3D; the order of calls matters.
- **`Principle3d`** `type Principle3d = (signal: Signal<Pose3d>) => Signal<Pose3d>`: Wraps the 3D signal of every motion above it on an object in a `.modify` call.
- **`SceneMotion3d`** `type SceneMotion3d = (time: Time, context: MotionContext) => Pose3d`: A motion on an object: a core `Motion` over `Pose3d`, or a plain function from time and context to one.
- **`MotionContext`** `type MotionContext = { time: Time; events: Events; index?: number; count?: number; line?: number; rest: RestReader; carry: Carry; element: string; span: Span | undefined; read: (element: Element | string, at?: ReadAt) => Pose2d }`: What a motion reads each frame, beside the time it plays in.
- **`Principle`** `type Principle = (signal: Signal<Pose2d>) => Signal<Pose2d>`: Wraps the signal of every motion above it in a `.modify` call.
- **`ReadAt`** `type ReadAt = { time?: Time; index?: number; count?: number }`: Where `read` looks: another time, or another part of a list.
- **`SceneBuilder`** `type SceneBuilder = { kind: "scene"; element: { (element: ObjectElement): ObjectStep; (element: Element): ElementStep; }; include: (scene: SceneBuilder) => SceneBuilder }`: A piece being written; `.element` selects what to give motions, and `compileScene` makes it playable.
- **`SceneBuilderOptions`** `type SceneBuilderOptions = { name?: string | undefined; cues?: Events | undefined; length?: number | undefined }`: Options of `sceneBuilder`: what is true of the whole piece.
- **`SceneMotion`** `type SceneMotion = (time: Time, context: MotionContext) => Pose2d`: A core `Motion`, or a plain function from time and context to a pose.
- **`ShowWindow`** `type ShowWindow = Beat | readonly [from: Beat, to: Beat] | { readonly from: Beat; } | { readonly until: Beat; }`: A beat; two beats, from the start of the first to the end of the second; from a beat's start on; or until a beat's end.
- **`StaggerBy`** `type StaggerBy = "index" | "line"`: Whether `stagger` orders lanes by part index or by measured visual line.
- **`StaggerFrom`** `type StaggerFrom = "start" | "end" | "center" | "edges"`: Which part of a staggered list starts first.
- **`StaggerOptions`** `type StaggerOptions = { spread: number; from?: StaggerFrom | undefined; by?: StaggerBy | undefined }`: Settings of `stagger`: `spread` is the gap between starts in lane lengths, `from` is origin, `by` is order.
- **`TravelOptions`** `type TravelOptions = { to: Element; arc?: number | undefined; fit?: "contain" | "fill" | undefined }`: Options of `travel`: target slot element, optional perpendicular arc bend in px, and how it fits the slot.
- **`NO_REST`** `const NO_REST: RestReader`: A reader with no boxes, as headless runs have.
- **`ZERO_BOX`** `const ZERO_BOX: Box`: Zero box answered for a name never measured.
- **`restReader`** `(rest?: Rest): RestReader`: A `RestReader` over `rest`.
- **`Box`** `type Box = { x: number; y: number; width: number; height: number }`: Where a member rests once laid out: its centre and size in frame px.
- **`Carry`** `type Carry = (member: string, options: CarryOptions) => Pose2d`: Moves `member` from its old rest box to its new one after a re-measure, over `options.ms`.
- **`CarryMode`** `type CarryMode = "scale" | "clip" | "keep"`: How a carried member takes the size of its target box.
- **`CarryOptions`** `type CarryOptions = { ms: number; ease?: Ease | undefined; mode?: CarryMode | undefined; target?: ((events: Events, rest: RestReader) => Box) | undefined }`: Options of `carry`: transition length, easing, sizing, and an optional target box.
- **`Rest`** `type Rest = { readonly [x: string]: Box; }`: Rest boxes by member name.
- **`RestAt`** `type RestAt = { at: number; rest: RestReader }`: What a mount measured at `at` ms on its clock.
- **`RestReader`** `type RestReader = { get: (name: string) => Box; has: (name: string) => boolean; keys: () => readonly string[] }`: Reads rest boxes; a name never measured answers a zero box.
- **`Limits`** `type Limits = { jump?: number | undefined; turn?: number | undefined; ratio?: number | undefined }`: Review limits of one target, overriding the command's defaults.
- **`ListPose`** `type ListPose = (index: number, count: number) => Pose2d`: A list's pose in the scene: the pose of item `index` of `count`.
- **`Drive`** `type Drive = { readonly kind: "scroll"; readonly beats: readonly ScrollBeat[]; } | { readonly kind: "trigger"; readonly beat: TriggerBeat; } | { readonly kind: "more"; }`: What drives an element: only scroll, through scroll beats without `smooth`; only one trigger beat's progress; or more, such as the clock, a spring, events or another element.
- **`Moves`** `type Moves = "time" | "maybe"`: How an element can change with no new input: `time` while a beat, trigger or spring is still running; `maybe` when a motion read the clock or another element, or has no window.
