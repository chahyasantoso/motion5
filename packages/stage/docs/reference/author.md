# @gerak/stage: author

What a piece is written with: `scene`, its elements, beats and motions. Reach for it whenever you write a piece.

- **`Content`** `type Content = { readonly kind: "box"; } | { readonly kind: "text"; } | { readonly kind: "readout"; readonly format: (time: Time) => string; } | { readonly kind: "stroke"; readonly path: Path; } | { readonly kind: "morph"; readonly shapes: readonly (readonly Cubic2d[])[]; }`: What an actor shows; `morph` holds its base outline first, then each target outline.
- **`Expect`** `type Expect = "settle" | "ambient" | "static"`: What review expects of a member: it moves and settles, it keeps moving, or the scene never poses it.
- **`Path`** `type Path = readonly Cubic2d[] | ((rest: RestReader) => readonly Cubic2d[])`: A stroke's outline: fixed cubics, or cubics drawn from the rest boxes of other members.
- **`ScrollWindow`** `type ScrollWindow = { readonly kind: "range"; readonly from: ScrollPoint; readonly to: ScrollPoint; } | { readonly kind: "from"; readonly from: ScrollPoint; } | { readonly kind: "until"; readonly until: ScrollPoint; }`: When a member shows in scroll px: bounded `[from, to)`, `{ from }`, or `{ until }`.
- **`beat`** `(name: string, ms: number, place?: BeatPlace): Beat (+2 overloads)`: A clock beat `ms` long, a triggered beat `{ when, back }`, or a scroll window `{ scroll: [from, to] }`.
- **`scrollPoint`** `(px: number): ScrollPoint`: A scroll position in `px`, with `.plus(px)`, `.minus(px)` and `.reached`.
- **`Beat`** `type Beat = { name: string; from: number; to: number; of: (time: Time, ease?: Ease) => Time; at: (share: number) => number }`: A named stretch of the piece in ms: a core `Span` that also says what it is called.
- **`BeatContext`** `type BeatContext = { events?: Events | undefined; rest?: RestReader | undefined }`: Context a scroll or trigger beat reads when mapping time: events so far and measured rests.
- **`BeatPlace`** `type BeatPlace = { readonly at?: number; } | { readonly after: Beat; readonly gap?: number; }`: Where a clock beat starts: at a ms (default 0), or after another beat with an optional gap.
- **`ScrollBeat`** `type ScrollBeat = { kind: "scroll-beat"; name: string; from: ScrollPoint; to: ScrollPoint; smooth: boolean; of: (time: Time, ease?: Ease, context?: BeatContext) => Time; active: (time: Time, context?: BeatContext) => boolean; moving: (time: Time, context?: BeatContext) => boolean }`: A named window over scroll position, mapping `from` to `to` into progress 0 to 1.
- **`ScrollBeatOptions`** `type ScrollBeatOptions = { scroll: readonly [from: ScrollPoint, to: ScrollPoint]; smooth?: true | SpringToOptions }`: Settings of a scroll beat: `[from, to]` scroll points mapping 0 to 1, and `smooth` to trail the scroll.
- **`ScrollPoint`** `type ScrollPoint = { kind: "scroll-point"; at: (rest?: RestReader) => number; plus: (px: number) => ScrollPoint; minus: (px: number) => ScrollPoint; reached: ScrollReached }`: A scroll position or an element's edge in px, resolved against measured page rest boxes.
- **`ScrollReached`** `type ScrollReached = { kind: "scroll-reached"; point: ScrollPoint }`: A trigger condition that fires when scroll passes `point`.
- **`TriggerBack`** `type TriggerBack = "reverse" | "stay" | "replay"`: What scrolling back past a trigger point does: reverse cleanly, stay at its end, or reset to replay.
- **`TriggerBeat`** `type TriggerBeat = { kind: "trigger-beat"; name: string; ms: number; when: ScrollReached; back: TriggerBack; of: (time: Time, ease?: Ease, context?: BeatContext) => Time; active: (time: Time, context?: BeatContext) => boolean; moving: (time: Time, context?: BeatContext) => boolean; heading: (time: Time, context?: BeatContext) => -1 | 0 | 1 }`: A named clock beat started when scroll passes `when.point`, with explicit `back` behaviour.
- **`TriggerPlace`** `type TriggerPlace = { when: ScrollReached; back: TriggerBack }`: Settings of a triggered clock beat: `when` scroll passes a point, and what scrolling `back` does.
- **`box`** `<N extends string = string>(name: N, options: BoxOptions & { readonly parts: true; }): Element & { readonly name: N; readonly parts: true; } (+1 overloads)`: A page element styled by CSS; `parts: true` binds it to a list of parts.
- **`object`** `<N extends string = string>(name: N, options: ObjectOptions & { readonly parts: true; }): ObjectElement & { readonly name: N; readonly parts: true; } (+1 overloads)`: A Three.js object; `parts: true` binds it to an `Object3D[]` or `Group`'s children.
- **`shape`** `<N extends string = string>(name: N, outline: ShapeSource, options?: ElementOptions): Element & { readonly name: N; }`: A drawn path, or a morph between outlines: 0 is `base`, 1 is `targets[0]`.
- **`text`** `<N extends string = string>(name: N, options?: TextOptions): Element & { readonly name: N; } (+1 overloads)`: Text in the markup, or text a function of time writes; `split` gives one part per letter or word.
- **`BoxOptions`** `type BoxOptions = { parts?: boolean | undefined; media?: boolean | undefined; watch?: boolean | undefined }`: Options of `box`: whether it binds to a list of parts, or a media clip.
- **`Element`** `type Element = ElementBody & Edges & ElementMethods`: An element of a piece, made once with a name; `kind` says what it is.
- **`Edges`** `type Edges = { top: ScrollPoint; end: ScrollPoint; pinStart: ScrollPoint; pinEnd: ScrollPoint }`: An element's measured edges as scroll points: top, end, and sticky pin start/end.
- **`ElementBody`** `type ElementBody = { readonly kind: "box"; readonly name: string; readonly parts?: boolean | undefined; readonly media?: true | undefined; readonly options: ElementOptions; } | { readonly kind: "shape"; readonly name: string; readonly outline: Outline; readonly options: ElementOptions; } | { readonly kind: "text"; readonly name: string; readonly content?: ((time: Time) => string) | undefined; readonly split: "letters" | "words" | undefined; readonly options: ElementOptions; }`: What an element is, before its edges.
- **`ElementOptions`** `type ElementOptions = { watch?: boolean | undefined }`: What stays true of an element in any scene: whether pointer events reach it.
- **`ObjectElement`** `type ObjectElement = { kind: "object"; name: string; view: ObjectView | undefined; parts?: boolean | undefined; moves: { (...motions: readonly SceneMotion3d[]): ObjectBinding; (...motions: readonly (SceneMotion3d | TravelMotion)[]): ObjectBinding; }; modifies: (principle: Principle3d) => ObjectBinding; shows: (...windows: readonly ShowWindow[]) => ObjectBinding; limits: (limits: Limits) => ObjectBinding }`: A Three.js object of a piece, posed in `Pose3d` world units and drawn by `threeBinder`, never by a DOM renderer.
- **`ObjectOptions`** `type ObjectOptions = { view?: ObjectView | undefined; parts?: boolean | undefined }`: Options of `object`: its view for slot travel, and whether `parts: true` binds a list of objects.
- **`ObjectView`** `type ObjectView = { canvas: Element; lens: Lens3d }`: Where an object is drawn: the element bound to the page's canvas, and the fixed lens the page draws through.
- **`SceneElement`** `type SceneElement = Element | ObjectElement`: Any element of a piece: one a DOM renderer draws, or a Three.js object.
- **`MorphSource`** `type MorphSource = { base: readonly Cubic2d[]; targets: readonly (readonly Cubic2d[])[] }`: A base outline with the outlines it blends to.
- **`Outline`** `type Outline = { readonly kind: "path"; readonly path: Path; } | { readonly kind: "morph"; readonly base: readonly Cubic2d[]; readonly targets: readonly (readonly Cubic2d[])[]; }`: What a shape draws: a path, or a base outline with the outlines it blends to.
- **`ShapeSource`** `type ShapeSource = Path | MorphSource`: What `shape` draws: a path, or a morph.
- **`TextOptions`** `type TextOptions = { split?: "letters" | "words" | undefined; watch?: boolean | undefined }`: Options of `text`: how to split it into parts.
- **`bind`** `(fields: BoundFields): Motion<Pose2d, MotionContext>`: A motion setting each field from its signal at the scene's time.
- **`bindEach`** `(fields: BoundEachSharedFields): Motion<SharedPose, MotionContext> (+2 overloads)`: A motion setting each field of each part of a 2D or 3D list from that part's signal at the scene's time.
- **`carry`** `(options: CarryOptions): Motion<Pose2d, MotionContext>`: A motion giving the element's move from its old rest box to its new one after a re-measure. A part of a list uses its box named `<element>.<index>`.
- **`compileScene`** `(scene: Scene, options?: CompileSceneOptions): CompileResult`: The stage a scene plays as, or every reason it cannot.
- **`isScene`** `(value: unknown): value is Scene`: Whether `value` is a piece made by `scene`.
- **`scene`** `(options: SceneOptions, ...items: readonly SceneItem[]): Scene (+1 overloads)`: A piece from its options and items: each element's binding, an element with no motion, or a scene taken in on the same clock. An element is bound once per scene.
- **`shot`** `(scene: Scene, options?: ShotOptions): Shot`: A shot of `scene`: inside it, time and events start at 0 when the shot starts.
- **`slot3d`** `(slot: Element, view: ObjectView, context: MotionContext, options?: Slot3dOptions): Slot3d | undefined`: Projects a page `slot` element through `view` into 3D world space for the active `context`.
- **`stagger`** `<P extends Pose2d | Pose3d>(inner: Motion<P, MotionContext>, options: StaggerOptions): Motion<P, MotionContext> (+1 overloads)`: Plays `inner` on each list part (2D or 3D) in its own lane; with no parts it plays as is. A function builds each part from `(index, count)`.
- **`stayWith`** `(element: Element): Motion<Pose2d, MotionContext>`: A motion giving the change in `element`'s pose since the start of its own clock span; it reads `element`.
- **`travel`** `(options: TravelOptions): TravelMotion`: Moves an element from its current pose into `options.to`'s measured box over its beat; with no window it sits there on every clock (live, timed, and untimed).
- **`Slot3d`** `type Slot3d = { center: Point3d; scale: number; width: number; height: number; view: ViewSize3d }`: Projected viewport slot in 3D world space: world-unit center, width, height, view, and fit scale.
- **`Slot3dOptions`** `type Slot3dOptions = { depth?: number | undefined; fit?: "none" | "contain" | undefined; scrollY?: number | undefined }`: Options of `slot3d`: explicit depth along the view, fit mode, and scroll offset override.
- **`BoundEachFields`** `type BoundEachFields = { readonly layer?: (index: number) => Signal<number>; readonly x?: (index: number) => Signal<number>; readonly scale?: (index: number) => Signal<number>; readonly y?: (index: number) => Signal<number>; readonly rotation?: (index: number) => Signal<number>; readonly skewX?: (index: number) => Signal<number>; readonly skewY?: (index: number) => Signal<number>; readonly scaleX?: (index: number) => Signal<number>; readonly scaleY?: (index: number) => Signal<number>; readonly opacity?: (index: number) => Signal<number>; readonly blur?: (index: number) => Signal<number>; readonly shadowX?: (index: number) => Signal<number>; readonly shadowY?: (index: number) => Signal<number>; readonly shadowBlur?: (index: number) => Signal<number>; readonly hue?: (index: number) => Signal<number>; readonly lightness?: (index: number) => Signal<number>; readonly tint?: (index: number) => Signal<number>; readonly drawn?: (index: number) => Signal<number>; readonly drawnFrom?: (index: number) => Signal<number>; readonly clipX?: (index: number) => Signal<number>; readonly clipY?: (index: number) => Signal<number>; readonly clipRadius?: (index: number) => Signal<number>; readonly clipWidth?: (index: number) => Signal<number>; readonly clipHeight?: (index: number) => Signal<number>; readonly shape?: (index: number) => Signal<number>; } & { readonly z?: never; readonly rotationX?: never; readonly rotationY?: never; readonly scaleZ?: never; }`: The 2D fields `bindEach` sets: each maps a part's index to its signal.
- **`BoundEachFields3d`** `type BoundEachFields3d = { readonly x?: (index: number) => Signal<number>; readonly scale?: (index: number) => Signal<number>; readonly y?: (index: number) => Signal<number>; readonly z?: (index: number) => Signal<number>; readonly rotation?: (index: number) => Signal<number>; readonly rotationX?: (index: number) => Signal<number>; readonly rotationY?: (index: number) => Signal<number>; readonly scaleX?: (index: number) => Signal<number>; readonly scaleY?: (index: number) => Signal<number>; readonly scaleZ?: (index: number) => Signal<number>; readonly opacity?: (index: number) => Signal<number>; } & { readonly layer?: never; readonly skewX?: never; readonly skewY?: never; readonly blur?: never; readonly shadowX?: never; readonly shadowY?: never; readonly shadowBlur?: never; readonly hue?: never; readonly lightness?: never; readonly tint?: never; readonly drawn?: never; readonly drawnFrom?: never; readonly clipX?: never; readonly clipY?: never; readonly clipRadius?: never; readonly clipWidth?: never; readonly clipHeight?: never; readonly shape?: never; }`: The 3D fields `bindEach` sets on an `object(..., { parts: true })`: each maps a part's index to its signal.
- **`BoundEachSharedFields`** `type BoundEachSharedFields = { readonly x?: (index: number) => Signal<number>; readonly scale?: (index: number) => Signal<number>; readonly y?: (index: number) => Signal<number>; readonly rotation?: (index: number) => Signal<number>; readonly scaleX?: (index: number) => Signal<number>; readonly scaleY?: (index: number) => Signal<number>; readonly opacity?: (index: number) => Signal<number>; } & { readonly layer?: never; readonly z?: never; readonly rotationX?: never; readonly rotationY?: never; readonly skewX?: never; readonly skewY?: never; readonly scaleZ?: never; readonly blur?: never; readonly shadowX?: never; readonly shadowY?: never; readonly shadowBlur?: never; readonly hue?: never; readonly lightness?: never; readonly tint?: never; readonly drawn?: never; readonly drawnFrom?: never; readonly clipX?: never; readonly clipY?: never; readonly clipRadius?: never; readonly clipWidth?: never; readonly clipHeight?: never; readonly shape?: never; }`: The shared fields `bindEach` sets: valid on both 2D list elements and 3D list objects.
- **`BoundFields`** `type BoundFields = { layer?: Signal<number>; x?: Signal<number>; scale?: Signal<number>; y?: Signal<number>; rotation?: Signal<number>; skewX?: Signal<number>; skewY?: Signal<number>; scaleX?: Signal<number>; scaleY?: Signal<number>; opacity?: Signal<number>; blur?: Signal<number>; shadowX?: Signal<number>; shadowY?: Signal<number>; shadowBlur?: Signal<number>; hue?: Signal<number>; lightness?: Signal<number>; tint?: Signal<number>; drawn?: Signal<number>; drawnFrom?: Signal<number>; clipX?: Signal<number>; clipY?: Signal<number>; clipRadius?: Signal<number>; clipWidth?: Signal<number>; clipHeight?: Signal<number>; shape?: Signal<number> }`: The fields `bind` sets: any numeric field of a pose.
- **`CompileSceneOptions`** `type CompileSceneOptions = { wrap?: ((run: Stage["scene"]) => Stage["scene"]) | undefined }`: How a scene compiles: a wrap around each frame's poses.
- **`Scene`** `type Scene = { kind: "scene" }`: A piece made by `scene`; `compileScene` makes it playable, and another `scene` can take it in.
- **`SceneItem`** `type SceneItem = Element | ObjectElement | ObjectBinding | Scene | ElementBinding | Shot`: What `scene` takes after its options: an element's binding, an element with no motion, or a scene.
- **`SceneOptions`** `type SceneOptions = { kind?: never; name?: string | undefined; cues?: Events | undefined; length?: number | undefined }`: Options of `scene`: what is true of the whole piece.
- **`Shot`** `type Shot = { kind: "shot"; scene: Scene; options: ShotOptions }`: A scene written from 0 that `scene` plays after the shot before it.
- **`ShotOptions`** `type ShotOptions = { name?: string | undefined; length?: number | undefined; until?: number | undefined; overlap?: number | undefined }`: Options of `shot`: its name, its length or the scene ms it ends at, and how far it starts before the last ends.
- **`SharedPose`** `type SharedPose = { x?: number; scale?: number; y?: number; rotation?: number; scaleX?: number; scaleY?: number; opacity?: number }`: The numeric fields shared by 2D and 3D poses: `x`, `y`, `rotation`, scales, and `opacity`.
- **`StaggerBy`** `type StaggerBy = "index" | "line"`: Whether `stagger` orders lanes by part index or by measured visual line.
- **`StaggerFrom`** `type StaggerFrom = "start" | "end" | "center" | "edges"`: Which part of a staggered list starts first.
- **`StaggerOptions`** `type StaggerOptions = { spread: number; from?: StaggerFrom | undefined; by?: StaggerBy | undefined }`: Settings of `stagger`: `spread` is the gap between starts in lane lengths, `from` is origin, `by` is order.
- **`BindingStep`** `type BindingStep = { readonly kind: "moves"; readonly motions: readonly SceneMotion[]; } | { readonly kind: "modifies"; readonly principle: Principle; } | { readonly kind: "shows"; readonly windows: readonly ShowWindow[]; } | { readonly kind: "limits"; readonly limits: Limits; }`: One call on an element's binding, kept in the order written.
- **`ElementBinding`** `type ElementBinding = { kind: "binding"; element: Element; steps: readonly BindingStep[]; moves: (...motions: readonly SceneMotion[]) => ElementBinding; modifies: (principle: Principle) => ElementBinding; shows: (...windows: readonly ShowWindow[]) => ElementBinding; limits: (limits: Limits) => ElementBinding }`: What an element does in a scene: each call returns a new binding, and the element never changes.
- **`ElementMethods`** `type ElementMethods = { moves: (...motions: readonly SceneMotion[]) => ElementBinding; modifies: (principle: Principle) => ElementBinding; shows: (...windows: readonly ShowWindow[]) => ElementBinding; limits: (limits: Limits) => ElementBinding }`: The binding methods every element carries.
- **`MotionContext`** `type MotionContext = { time: Time; events: Events; index?: number; count?: number; line?: number; rest: RestReader; carry: Carry; element: string; span: Span | undefined; read: { (element: ObjectElement, at?: ReadAt): Pose3d; (element: Element | string, at?: ReadAt): Pose2d; } }`: What a motion reads each frame, beside the time it plays in.
- **`ObjectBinding`** `type ObjectBinding = { kind: "object-binding"; element: ObjectElement; steps: readonly ObjectBindingStep[]; moves: { (...motions: readonly SceneMotion3d[]): ObjectBinding; (...motions: readonly (SceneMotion3d | TravelMotion)[]): ObjectBinding; }; modifies: (principle: Principle3d) => ObjectBinding; shows: (...windows: readonly ShowWindow[]) => ObjectBinding; limits: (limits: Limits) => ObjectBinding }`: What an object does in a scene, in 3D: each call returns a new binding, and the object never changes.
- **`ObjectBindingStep`** `type ObjectBindingStep = { readonly kind: "moves"; readonly motions: readonly (SceneMotion3d | TravelMotion)[]; } | { readonly kind: "modifies"; readonly principle: Principle3d; } | { readonly kind: "shows"; readonly windows: readonly ShowWindow[]; } | { readonly kind: "limits"; readonly limits: Limits; }`: One call on an object's binding, kept in the order written.
- **`ObjectMethods`** `type ObjectMethods = { moves: { (...motions: readonly SceneMotion3d[]): ObjectBinding; (...motions: readonly (SceneMotion3d | TravelMotion)[]): ObjectBinding; }; modifies: (principle: Principle3d) => ObjectBinding; shows: (...windows: readonly ShowWindow[]) => ObjectBinding; limits: (limits: Limits) => ObjectBinding }`: The binding methods every object carries.
- **`Principle`** `type Principle = (signal: Signal<Pose2d>) => Signal<Pose2d>`: Wraps the signal of every motion written before it in a `.modifies` call.
- **`Principle3d`** `type Principle3d = (signal: Signal<Pose3d>) => Signal<Pose3d>`: Wraps the 3D signal of every motion written before it on an object in a `.modifies` call.
- **`ReadAt`** `type ReadAt = { time?: Time; index?: number; count?: number }`: Where `read` looks: another time, or another part of a list.
- **`SceneMotion`** `type SceneMotion = (time: Time, context: MotionContext) => Pose2d`: A core `Motion`, or a plain function from time and context to a pose.
- **`SceneMotion3d`** `type SceneMotion3d = (time: Time, context: MotionContext) => Pose3d`: A motion on an object: a core `Motion` over `Pose3d`, or a plain function from time and context to one.
- **`ShowWindow`** `type ShowWindow = Beat | ScrollBeat | readonly [from: Beat, to: Beat] | readonly [from: ScrollPoint, to: ScrollPoint] | { readonly from: Beat; } | { readonly until: Beat; } | { readonly from: ScrollPoint; } | { readonly until: ScrollPoint; }`: A clock beat or scroll beat; `[from, to]` of either; `{ from }`; or `{ until }`.
- **`TravelMotion`** `type TravelMotion = { (time: Time, context?: MotionContext | undefined): Pose2d; travel: TravelOptions; in: (window: InWindow, ease?: Ease) => TravelMotion; loop: (ms: number) => TravelMotion; take: () => TravelMotion; ambient: () => TravelMotion; span: Span | undefined; window: InWindow | undefined; period: number | undefined; joins: Joins; loopsForever: boolean; isAmbient: boolean }`: What `travel` returns: a motion on an element, which an object with a view also takes.
- **`TravelOptions`** `type TravelOptions = { to: Element; arc?: number | undefined; fit?: "none" | "contain" | "fill" | undefined }`: Options of `travel`: target slot element, optional perpendicular arc bend in px, and how it fits the slot.
- **`NO_REST`** `const NO_REST: RestReader`: A reader with no boxes, as headless runs have.
- **`ZERO_BOX`** `const ZERO_BOX: Box`: Zero box answered for a name never measured.
- **`restReader`** `(rest?: Rest, objects?: ObjectRest): RestReader`: A `RestReader` over `rest` and optional 3D `objects`.
- **`Box`** `type Box = { x: number; y: number; width: number; height: number }`: Where a member rests once laid out: its centre and size in frame px.
- **`Carry`** `type Carry = (member: string, options: CarryOptions) => Pose2d`: Moves `member` from its old rest box to its new one after a re-measure, over `options.ms`.
- **`CarryMode`** `type CarryMode = "scale" | "clip" | "keep"`: How a carried member takes the size of its target box.
- **`CarryOptions`** `type CarryOptions = { ms: number; ease?: Ease | undefined; mode?: CarryMode | undefined; target?: ((events: Events, rest: RestReader) => Box) | undefined }`: Options of `carry`: transition length, easing, sizing, and an optional target box.
- **`ObjectBounds3d`** `type ObjectBounds3d = { width: number; height: number; depth: number }`: Measured world-unit bounding box size of a bound 3D object at rest.
- **`ObjectRest`** `type ObjectRest = { readonly [x: string]: ObjectBounds3d; }`: Measured rest sizes of 3D object members by name.
- **`Rest`** `type Rest = { readonly [x: string]: Box; }`: Rest boxes by member name.
- **`RestAt`** `type RestAt = { at: number; rest: RestReader }`: What a mount measured at `at` ms on its clock.
- **`RestReader`** `type RestReader = { get: (name: string) => Box; has: (name: string) => boolean; keys: () => readonly string[]; object: (name: string) => ObjectBounds3d | undefined }`: Reads rest boxes and 3D object sizes; an unmeasured box answers a zero box.
- **`Limits`** `type Limits = { jump?: number | undefined; turn?: number | undefined; ratio?: number | undefined }`: Review limits of one target, overriding the command's defaults.
- **`ListPose`** `type ListPose = (index: number, count: number) => Pose2d`: A list's pose in the scene: the pose of item `index` of `count`.
- **`ListPose3d`** `type ListPose3d = (index: number, count: number) => Pose3d`: A 3D list's pose in the scene: the 3D pose of item `index` of `count`.
- **`Drive`** `type Drive = { readonly kind: "scroll"; readonly beats: readonly ScrollBeat[]; } | { readonly kind: "trigger"; readonly beat: TriggerBeat; } | { readonly kind: "more"; }`: What drives an element: only scroll, through scroll beats without `smooth`; only one trigger beat's progress; or more, such as the clock, a spring, events or another element.
- **`Moves`** `type Moves = "time" | "maybe"`: How an element can change with no new input: `time` while a beat, trigger or spring is still running; `maybe` when a motion read the clock or another element, or has no window.
- **`ShotSummary`** `type ShotSummary = { name: string; index: number; from: number; to: number; overlap: number }`: One shot of a scene made with `shot`: its name, place in order, and its ms on the scene's clock.
