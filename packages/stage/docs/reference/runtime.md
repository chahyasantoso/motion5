# @gerak/stage: runtime

Authoring entry point (`defineStage`), frame evaluation (`evaluateFrame`), and scene shape validation. Reach for this group when writing or running a stage piece.

- **`defineStage`** `<P extends PoseMode = "2d", const B extends string = string, C extends Readonly<Record<string, Member<B>>> = Readonly<Record<string, Member<B>>>, const L extends string = never>(options: StageOptions<P, B, C, L>): StageDefinition<P, B, C, L>`: Declares a typed, deterministic stage piece connecting beats, cast, layouts, skins, and scene.
- **`evaluateFrame`** `<P extends PoseMode = "2d">(stage: CompiledStage<P>, input: FrameInput): FrameEvaluation<P>`: Evaluates `stage` at `{ time, events, boxes }` with shape checks, readouts, visibility, and morphs.
- **`validateSceneOutput`** `(members: CompiledMembers, output: unknown): { readonly ok: true; } | { readonly ok: false; readonly errors: readonly ShapeMismatchError[]; }`: Single-owner shape check enforcing actor/group objects and exact-length list arrays.
- **`FrameEvaluation`** `type FrameEvaluation<P> = { readonly ok: true; readonly layout: string | undefined; readonly visibility: Readonly<Record<string, boolean>>; readonly poses: Readonly<Record<string, PoseFor<P> | readonly PoseFor<P>[]>>; readonly readouts: Readonly<Record<string, string>>; readonly readoutErrors: readonly { readonly member: string; readonly error: unknown; }[]; readonly morphs: Readonly<Record<string, readonly Cubic2d[]>>; readonly extraTargets: readonly string[]; } | { readonly ok: false; readonly errors: readonly ShapeMismatchError[]; }`: Evaluated frame output ready for renderers and headless review.
- **`FrameInput`** `type FrameInput<L> = { time: Time; events?: Events | undefined; boxes?: RestReader | Readonly<Record<L, RestReader>> | undefined }`: Inputs to `evaluateFrame`: current `time`, accumulated `events`, and optional measured `boxes`.
- **`ShapeMismatchError`** `type ShapeMismatchError = { kind: "shape_mismatch"; member: string; reason: string }`: Shape mismatch error variant returned by `validateSceneOutput` and `evaluateFrame`.
