# @gerak/stage docs

Who is on stage and when. Pages for a brief that needs more than the loop are named in the table.

- [stage.md](./stage.md): read whole before making a piece: the loop, the stage module, the traps.
- [Events](./agent-events.md), [layout](./agent-layout.md) and [live inputs](./agent-inputs.md).
- [Reference](./reference/README.md): every export with its signature, by source folder.

| The brief has | Read |
| --- | --- |
| Hover, press, click, scroll into view, or one target answering another's moment | [events](./agent-events.md) |
| Many bodies, collisions, a pile, things thrown and falling | [physics](../../physics/docs/agent-physics.md) |
| An arm, a leg, a figure: bones that reach | [rigs](../../rig/docs/agent-rigs.md) |
| Weight, life, character or polish: anticipation, arcs, follow-through, settle | [principles](../../moves/docs/agent-principles.md) |
| Depth, turns about several axes, a moving camera: a Three.js scene | [3D](../../three/docs/agent-3d.md) |
| A motion with a name that no catalogued move gives | [writing a move](../../moves/docs/agent-moves.md) |
| A value from where the layout puts a member; a route change, a card that opens, a list that reorders | [layout](./agent-layout.md) |
| A supplied drawing or SVG to animate, or a character to draw and rig | [artwork](../../tools/docs/agent-artwork.md) |
| Numbers arriving while it plays: a microphone, a slider, a recorded session | [live inputs](./agent-inputs.md) |
| A person watching edits land as you save | [live editing](../../tools/docs/live.md) |
| A page outside this repository, or a real site's own elements | [outside the stage](../../dom/docs/agent-outside.md) |
| A piece in another brief's style, or turning your brief into a style | [styles](../../moves/docs/agent-style.md) |
| A reel: several shots, a hook, a story and a call to action | [reels](../../moves/docs/agent-reel.md) |
