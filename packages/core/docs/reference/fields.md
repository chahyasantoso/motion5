# @gerak/core: fields

Pose fields, rest values, combining rules, and lifting 2D poses to 3D. Reach for this group when defining fields or combining poses.

- **`CUSTOM_FIELD`** `const CUSTOM_FIELD: ValueField`: A number a piece names itself, under `custom`: it rests at 0 and adds, and each renderer says where it goes.
- **`POSE_2D_FIELDS`** `const POSE_2D_FIELDS: readonly (CarriedBy<"both" | "2d"> | "anchor")[]`: Every field a renderer must write for a pose: its numbers and its anchor.
- **`VALUE_FIELDS`** `const VALUE_FIELDS: { x, y, z, rotation, rotationX, rotationY, skewX, skewY, scale, scaleX, scaleY, scaleZ, opacity, blur, shadowX, shadowY, shadowBlur, hue, lightness, tint, drawn, drawnFrom, clipX, clipY, clipRadius, clipWidth, clipHeight, shape, layer }`: Every field a value can carry, one row each; nothing else states a field's rest or how it combines.
- **`valueField`** `(name: string): ValueField | undefined`: The row a field name has in the table, or nothing when it has none.
- **`Anchor`** `type Anchor = "center" | "bottom" | "top" | "left" | "right"`: The point of a box that stays put while it scales and turns.
- **`Combining`** `type Combining = "add" | "multiply" | "replace"`: How two answers for one field on one target become one.
- **`Pose2d`** `type Pose2d = { readonly layer?: number; readonly x?: number; readonly scale?: number; readonly y?: number; readonly rotation?: number; readonly skewX?: number; readonly skewY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly opacity?: number; readonly blur?: number; readonly shadowX?: number; readonly shadowY?: number; readonly shadowBlur?: number; readonly hue?: number; readonly lightness?: number; readonly tint?: number; readonly drawn?: number; readonly drawnFrom?: number; readonly clipX?: number; readonly clipY?: number; readonly clipRadius?: number; readonly clipWidth?: number; readonly clipHeight?: number; readonly shape?: number; } & { readonly z?: never; readonly rotationX?: never; readonly rotationY?: never; readonly scaleZ?: never; } & { readonly anchor?: Anchor; readonly custom?: Readonly<Record<string, number>>; }`: A 2D pose, every field optional: `x`, `y`, `rotation`, `scale`, `scaleX`, `scaleY`, `opacity`, `anchor` and `custom` numbers. Stage px, y down, degrees clockwise; a `Pose3d` is refused.
- **`ValueField`** `type ValueField = { meaning: string; unit: "number" | "length" | "px" | "deg" | "scale" | "share" | "index" | "order"; dimension: "both" | "2d" | "3d"; rest?: number; combines: Combining; smooth: boolean; shows: boolean; least?: number; judged: "position" | "turn" | "ratio" }`: What a field of a value is: what it changes, its unit, which poses carry it, where it rests, how it combines, and what the gate asks of it.
- **`combine3d`** `(poses: readonly Pose3d[]): Pose3d`: Poses on one target as one: each field joins as its row says, custom numbers add, turns compose in order.
- **`lift2d`** `(pose: Pose2d, options: { readonly unitsPerPx: number; }): Pose3d`: A 2D pose on the 3D xy plane: px scaled by `unitsPerPx`, y and the turn flipped, the anchor dropped; every 2D move reaches 3D through it.
- **`Pose3d`** `type Pose3d = { readonly x?: number; readonly scale?: number; readonly y?: number; readonly z?: number; readonly rotation?: number; readonly rotationX?: number; readonly rotationY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly scaleZ?: number; readonly opacity?: number; } & { readonly anchor?: never; readonly custom?: Readonly<Record<string, number>>; }`: A 3D pose, every field optional: `x`, `y`, `z`, `rotation` (about z), `rotationX`, `rotationY`, scales, `opacity`. Y up, degrees on Z-X-Y; a `Pose2d` is refused.
- **`combine`** `(poses: readonly Pose2d[]): Pose2d`: Poses on one target as one: each field joins as its table row says, custom numbers add, the first anchor stays.
- **`POSE_2D_NUMBERS`** `const POSE_2D_NUMBERS: readonly CarriedBy<"both" | "2d">[]`: The numbers a 2D pose carries: the rows whose dimension is `2d` or `both`, in table order.
