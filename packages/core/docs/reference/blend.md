# @gerak/core: blend

Blending turns two values or poses into the value between them, and keyframes turns a list of keys into a curve. Reach for it to interpolate a number, an angle, a point or a whole pose.

- **`mix`** `(from: number, to: number, share: number): number`: The number `share` of the way from `from` to `to`; a share past 0 or 1 extrapolates.
- **`mixAngle`** `(from: number, to: number, share: number): number`: An angle in degrees `share` of the way from `from` to `to`, turning the short way round.
- **`mixPoint`** `(from: { readonly x: number; readonly y: number; }, to: { readonly x: number; readonly y: number; }, share: number): { readonly x: number; readonly y: number; }`: A point `share` of the way from `from` to `to`.
- **`mixPose`** `(from: { readonly x?: number; readonly scale?: number; readonly y?: number; readonly rotation?: number; readonly skewX?: number; readonly skewY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly opacity?: number; readonly blur?: number; readonly shadowX?: number; readonly shadowY?: number; readonly shadowBlur?: number; readonly hue?: number; readonly lightness?: number; readonly tint?: number; readonly drawn?: number; readonly drawnFrom?: number; readonly clipX?: number; readonly clipY?: number; readonly clipRadius?: number; readonly clipWidth?: number; readonly clipHeight?: number; readonly shape?: number; readonly layer?: number; } & { readonly anchor?: Anchor; readonly custom?: Readonly<Record<string, number>>; }, to: { readonly x?: number; readonly scale?: number; readonly y?: number; readonly rotation?: number; readonly skewX?: number; readonly skewY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly opacity?: number; readonly blur?: number; readonly shadowX?: number; readonly shadowY?: number; readonly shadowBlur?: number; readonly hue?: number; readonly lightness?: number; readonly tint?: number; readonly drawn?: number; readonly drawnFrom?: number; readonly clipX?: number; readonly clipY?: number; readonly clipRadius?: number; readonly clipWidth?: number; readonly clipHeight?: number; readonly shape?: number; readonly layer?: number; } & { readonly anchor?: Anchor; readonly custom?: Readonly<Record<string, number>>; }, share: number): { readonly x?: number; readonly scale?: number; readonly y?: number; readonly rotation?: number; readonly skewX?: number; readonly skewY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly opacity?: number; readonly blur?: number; readonly shadowX?: number; readonly shadowY?: number; readonly shadowBlur?: number; readonly hue?: number; readonly lightness?: number; readonly tint?: number; readonly drawn?: number; readonly drawnFrom?: number; readonly clipX?: number; readonly clipY?: number; readonly clipRadius?: number; readonly clipWidth?: number; readonly clipHeight?: number; readonly shape?: number; readonly layer?: number; } & { readonly anchor?: Anchor; readonly custom?: Readonly<Record<string, number>>; }`: A pose `share` of the way between two; a field one pose lacks counts as its rest, and a custom number as 0.
- **`keyframes`** `<T>(start: T, keys: readonly Key<T>[], blend: (from: T, to: T, share: number) => T): (time: Time) => T`: A value moving from `start` at 0 ms to each key in turn, then holding; `blend` is `mix`, `mixPoint`, `mixPose` or alike.
- **`Key`** `type Key<T> = { at: number; to: T; ease?: Ease | undefined }`: One keyframe: the value reached at `at` ms, eased from the key before; with no `ease` it is linear.
- **`mixPoint3d`** `(from: { readonly x: number; readonly y: number; readonly z: number; }, to: { readonly x: number; readonly y: number; readonly z: number; }, share: number): { readonly x: number; readonly y: number; readonly z: number; }`: A 3D point `share` of the way from `from` to `to`.
- **`mixPose3d`** `(from: { readonly x?: number; readonly scale?: number; readonly y?: number; readonly z?: number; readonly rotation?: number; readonly rotationX?: number; readonly rotationY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly scaleZ?: number; readonly opacity?: number; } & { readonly anchor?: never; readonly custom?: Readonly<Record<string, number>>; }, to: { readonly x?: number; readonly scale?: number; readonly y?: number; readonly z?: number; readonly rotation?: number; readonly rotationX?: number; readonly rotationY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly scaleZ?: number; readonly opacity?: number; } & { readonly anchor?: never; readonly custom?: Readonly<Record<string, number>>; }, share: number): { readonly x?: number; readonly scale?: number; readonly y?: number; readonly z?: number; readonly rotation?: number; readonly rotationX?: number; readonly rotationY?: number; readonly scaleX?: number; readonly scaleY?: number; readonly scaleZ?: number; readonly opacity?: number; } & { readonly anchor?: never; readonly custom?: Readonly<Record<string, number>>; }`: A pose `share` of the way between two; turns take the short arc, past the ends too; a missing field rests.
