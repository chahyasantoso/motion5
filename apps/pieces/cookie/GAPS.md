# Warm Batch — Gerak Friction & Gap Log

Tracks architectural triage and real authoring friction discovered while building `apps/pieces/cookie/` on `feat/cookie-piece` (branched from `feat/authored-cast`). Triaged against Gerak's core invariants (**one owner per question**, **pure scene**, **build only when a brief proves the need**).

**Status:** 14 of 14 planned Tier-1/Tier-2 gaps closed across PR 1–PR 3 (`ADR-199`, `ADR-200`), and adopted across `apps/pieces/cookie/` (`G-01`, `G-02`, `G-03a`, `G-05`, `G-07`, `G-08`, `G-09`, `G-10`, `G-11`, `G-15`, `G-16` active on `cookie`; `G-04a` cylinder colliders and `G-06` `--sizes` available; `G-14` fast-forwards crumb physics). Five explicit boundary decisions (`G-12`, `G-13`, `G-03b`, `G-04b`, pixel 3D `arc`) remain deferred or rejected.

## Project vs Framework Boundary (`contract.ts` & `cookie-main.ts`)

- **`src/contract.ts` stays 100% project-level:** It owns Warm Batch domain configuration (`CastName`, `DomCast`, and `ObjectCast` re-exported from `../cookie.cast.ts`, `FLAVORS` copy/pricing/tints, `STAGE_SIZE`, `LENS`, `JAR_METRICS`). Moving site vocabulary or flavor tables into Gerak packages would introduce project coupling and a house look (explicitly excluded by `ARCHITECTURE.md` §6).
- **`@gerak/core` stays strictly pure:** Neither `contract.ts` nor `cookie-main.ts` belongs in `@gerak/core`. Core owns pure time, curves, signals, 3D math, and state folds — zero `window`, DOM, `ResizeObserver`, or Three.js types.
- **`src/cookie-main.ts` splits between project wiring and `G-07` renderer helpers:** Three.js studio construction (`world-studio.ts`), `.glb` assembly (`world-models.ts`), and page startup stay per-project, while only the two generic Gerak integration seams (`window.__motionReady` typing/registration in `@gerak/dom` and `binder.resize` synchronization in `@gerak/dom` + `@gerak/three`) warrant small framework helpers (`G-07`).

## Sequencing Outcome

All 5 Warm Batch sections initially shipped within Gerak while logging concrete friction above. Subsequent PRs (`ADR-199` for PR 1–PR 2, `ADR-200` for PR 3) closed all 14 planned Tier-1 and Tier-2 gaps (`G-01` through `G-11`, `G-14`, `G-15`, `G-16`) and refactored `apps/pieces/cookie/` across PR 2 and PR 3 (`space3d.ts` consolidated onto `viewSize3d` / `placementOf` / `.pinStart` / `.pinEnd`, manual transition clocks replaced with `transition()`, `ready()` + `threeBinder({ resize })` adopted, `PARKED_Z` deleted via scroll `.show()`, and 25 indexed `object(...)` casts collapsed into 4 `object(..., { parts: true })` list objects). The remaining 5 rows (`G-12`, `G-13`, `G-03b`, `G-04b`, and pixel 3D `arc`) stay intentionally deferred or rejected.
